1. KITEFRAME CANVAS - SETUP & PROPS
================================================================================

The KiteFrameCanvas is the main React component for rendering the visual
workflow editor. It provides an interactive canvas with drag-and-drop nodes,
connections (edges), zoom/pan controls, and plugin extensibility.

INSTALLATION & BASIC SETUP
---------------------------

```tsx
import { KiteFrameCanvas, PluginProvider } from '@kiteline/core';
import '@kiteline/core/styles/kiteframe.css';
import { useState } from 'react';

function App() {
  const [nodes, setNodes] = useState([]);
  const [edges, setEdges] = useState([]);
  const [viewport, setViewport] = useState({ x: 0, y: 0, zoom: 1 });

  return (
    <PluginProvider>
      <div style={{ width: '100vw', height: '100vh' }}>
        <KiteFrameCanvas
          nodes={nodes}
          edges={edges}
          viewport={viewport}
          onNodesChange={setNodes}
          onEdgesChange={setEdges}
          onViewportChange={setViewport}
          enablePlugins={true}
        />
      </div>
    </PluginProvider>
  );
}
```

CANVAS PROPS REFERENCE
----------------------

| Prop               | Type                              | Required | Description                           |
|--------------------|-----------------------------------|----------|---------------------------------------|
| nodes              | Node[]                            | Yes      | Array of node objects                 |
| edges              | Edge[]                            | Yes      | Array of edge connections             |
| viewport           | { x, y, zoom }                    | Yes      | Current canvas view state             |
| onNodesChange      | (nodes: Node[]) => void           | Yes      | Callback when nodes change            |
| onEdgesChange      | (edges: Edge[]) => void           | Yes      | Callback when edges change            |
| onViewportChange   | (viewport: Viewport) => void      | Yes      | Callback when viewport changes        |
| onNodeClick        | (nodeId: string) => void          | No       | Callback when node is clicked         |
| onEdgeClick        | (edgeId: string) => void          | No       | Callback when edge is clicked         |
| onCanvasClick      | () => void                        | No       | Callback when canvas is clicked       |
| enablePlugins      | boolean                           | No       | Enable plugin system (default: false) |
| showMinimap        | boolean                           | No       | Show minimap navigator                |
| showZoomControls   | boolean                           | No       | Show zoom +/- controls                |
| snapToGrid         | boolean                           | No       | Enable grid snapping                  |
| gridSize           | number                            | No       | Grid size in pixels (default: 20)     |
| proFeatures        | ProFeaturesConfig                 | No       | Pro features configuration            |
| core               | KiteFrameCore                     | No       | Custom core instance                  |

CREATING A PLUGIN
-----------------

```typescript
// myPlugin.ts
import { KiteFramePlugin, KiteFrameCore } from '@kiteline/core';

export const myPlugin: KiteFramePlugin = {
  name: 'my-custom-plugin',
  version: '1.0.0',
  
  initialize(core: KiteFrameCore) {
    // Register hooks
    core.registerHooks({
      afterNodesChange: (nodes) => {
        console.log('Nodes changed:', nodes.length);
      },
      onCanvasClick: (event, worldPos) => {
        console.log('Canvas clicked at:', worldPos);
      }
    });
    
    // Listen to events
    core.on('nodeSelected', (data) => {
      console.log('Node selected:', data.nodeId);
    });
  },
  
  cleanup() {
    console.log('Plugin cleanup');
  }
};
```

REGISTERING A PLUGIN
--------------------

```tsx
import { PluginProvider, usePluginSystem } from '@kiteline/core';
import { myPlugin } from './myPlugin';

function App() {
  const { usePlugin } = usePluginSystem();
  usePlugin(myPlugin);
  
  return (
    <PluginProvider>
      <KiteFrameCanvas enablePlugins={true} {...props} />
    </PluginProvider>
  );
}
```

4. FIGMA INTEGRATION
================================================================================

Kiteframe integrates with Figma via MCP (Model Context Protocol) tools.

AVAILABLE FIGMA MCP TOOLS
-------------------------

1. get_design_context
   - Generates UI code from Figma node
   - Primary tool for converting designs to code
   - Parameters: fileKey, nodeId, clientLanguages, clientFrameworks

2. get_screenshot
   - Captures screenshot of Figma node
   - Parameters: fileKey, nodeId

3. get_metadata
   - Gets node structure in XML format
   - Returns IDs, types, names, positions, sizes

4. get_variable_defs
   - Gets design system variables (colors, fonts, etc.)

5. get_code_connect_map
   - Maps Figma components to codebase locations

USAGE EXAMPLE
-------------

To import a Figma design:
1. Get Figma URL (e.g., https://figma.com/design/:fileKey/:fileName?node-id=1-2)
2. Extract fileKey and nodeId from URL
3. Call get_design_context with parameters
4. Use generated code to create nodes

URL PARSING
-----------
From: https://figma.com/design/pqrs/ExampleFile?node-id=1-2
- fileKey: pqrs
- nodeId: 1:2 (replace - with :)

For branch URLs: https://figma.com/design/:fileKey/branch/:branchKey/:fileName
- Use branchKey as fileKey

TAILWIND CSS NOTES
------------------
Some Tailwind v4 utilities need conversion to inline styles:
- mask-alpha → style={{maskMode: "alpha"}}
- text-shadow-* → style={{textShadow: "..."}}
- wrap-balance → style={{textWrap: "balance"}}

EDGE TYPES

| Type        | Description                              |
|-------------|------------------------------------------|
| straight    | Direct line connection                   |

Z-INDEX & LAYERING
------------------

Nodes and edges have zIndex properties for layering control.

```typescript
// Bring node to front
const bringToFront = (nodeId: string) => {
  const maxZ = Math.max(...nodes.map(n => n.zIndex || 0));
  setNodes(nodes.map(n => 
    n.id === nodeId ? { ...n, zIndex: maxZ + 1 } : n
  ));
};
```

Edge z-index is recalculated automatically based on connected nodes:
- client/src/lib/kiteframe/utils/edgeZIndex.ts

AUTO-LAYOUT OPTIONS
-------------------

5 built-in layout algorithms:
1. Horizontal Flow - Left to right arrangement
2. Vertical Flow - Top to bottom arrangement  
3. Grid - Rows and columns grid
4. Circular - Nodes arranged in circle
5. Hierarchical - Tree-like structure

IMPORT/EXPORT
-------------

Workflows can be serialized to JSON:

```typescript
interface WorkflowData {
  nodes: Node[];
  edges: Edge[];
  viewport?: Viewport;
  metadata?: WorkflowMetadata;
}

// Export
const exportWorkflow = () => JSON.stringify({ nodes, edges, viewport });

// Import
const importWorkflow = (json: string) => {
  const data = JSON.parse(json);
  setNodes(data.nodes);
  setEdges(data.edges);
};
```

ARCHITECTURE OVERVIEW
---------------------

The AI system uses an OpenAI-compatible client that routes through a backend
proxy. It supports multiple providers including OpenAI, local Ollama, and
custom endpoints.

AI CLIENT SETUP
---------------

```typescript
// client/src/ai/OpenAICompatClient.ts
export class OpenAICompatClient implements AiClient {
  constructor(opts: {
    baseURL: string;
    apiKey?: string;
    headers?: Record<string, string>;
    defaultModel?: string;
  });
  
  async chat(req: AiRequest): Promise<AiResponse>;
}

interface AiRequest {
  messages: Array<{ role: 'system' | 'user' | 'assistant'; content: string }>;
  model?: string;
  temperature?: number;
  maxTokens?: number;
}

interface AiResponse {
  text: string;
}
```
