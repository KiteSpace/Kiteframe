KITEFRAME — EXPORT SYSTEM REFACTOR

Machine-Executable Replit Task File

OBJECTIVE

Refactor the Project Export modal to support:

À-la-carte exports (single artifacts)

Bundle exports (multi-file, opinionated sets)

Multi-select export via checkboxes

Clear, user-facing descriptions of contents

Accurate naming (no PRD-only language)

This task replaces the existing single-select “Export Format” behavior.

GLOBAL RULES (NON-NEGOTIABLE)

Users must be able to select multiple exports at once

Bundles and individual files must coexist

No export option may be ambiguous about what files it produces

UI labels must match actual output exactly

No “Bundle” suffix in bundle option names

No references to “Export PRD” anywhere

STEP 1 — MODAL TITLE & ENTRY POINT
1.1 Modal title

REPLACE

Export Project PRD


WITH

Export Project

1.2 Project panel entry

Ensure the Project Panel uses:

⬇︎ Export


Icon + text (icon alone is not acceptable).

STEP 2 — EXPORT SELECTION MODEL (DATA)

Replace any single-select export model with a multi-select array.

type ExportOption =
  | 'prd_document'
  | 'prototype_prompt'
  | 'figma_make_prompt'
  | 'jira_csv'
  | 'kiteframe_project'
  | 'bundle_builder'
  | 'bundle_design'
  | 'bundle_project'
  | 'bundle_ai_agent'

type ExportSelection = ExportOption[]


Export is valid when:

selection.length > 0

STEP 5 — MULTI-SELECT BEHAVIOR RULES
5.1 Checkbox behavior

Users may select any combination of:

Individual files

Bundles

Selecting a bundle does not disable individual options

5.2 Deduplication rule

If the same artifact appears in multiple selections:

Export it once

Do not duplicate files in the final export

Example:

User selects Builder + Prototype Prompt

Prototype Prompt is exported once

5.3 Export packaging

If multiple files are selected:

Export as a single ZIP

Use clear filenames and folders

Example:

/export/
  /bundles/
    builder/
  /files/
    prd.md
    jira.csv


Exact structure is flexible, clarity is not.

STEP 6 — EMPTY / DISABLED STATES
6.1 No selection

Export button disabled

Helper text:

Select at least one item to export.

6.2 Missing prerequisites

If an export requires unavailable data:

Show inline warning on that option

Do NOT block the entire modal

Example:

PRD Document (requires generated PRD)

STEP 7 — ANALYTICS (INTERNAL)

Track:

}


Do NOT expose analytics terms in UI copy.

STEP 8 — ACCEPTANCE CHECKLIST (MUST PASS)

 Modal title is “Export Project”

 Users can select multiple exports at once

 Bundles and individual files are clearly separated

 Every option has a description

 Bundle contents match definitions exactly

 No duplicate files in output

 No mention of “Export PRD” anywhere

 “Bundle” does not appear in bundle option labels

FAILURE CONDITIONS

This task is FAILED if:

Only one export can be selected

Bundles obscure or replace individual exports

Descriptions are missing or vague

PRD language appears in modal title

Bundle contents drift from spec
