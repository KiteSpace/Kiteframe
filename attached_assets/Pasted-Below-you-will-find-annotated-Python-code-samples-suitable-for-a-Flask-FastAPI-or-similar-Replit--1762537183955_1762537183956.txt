1. Region Locking Logic (US Only)
Reasoning steps:
- Get the user's IP address (X-Forwarded-For first, fallback to remote_addr).
- Query a geolocation API (like ipinfo) to get the country code.
- Allow only if country is 'US'. Deny and exit otherwise.
- Perform this check on every sensitive endpoint.
--- Actual code sample ---
from flask import request, abort
import requests

def check_us_only():
# Get user IP address from request headers or remote_addr
user_ip = request.headers.get('X-Forwarded-For', request.remote_addr)

# Use a geo API to determine country
geo_url = f'https://ipinfo.io/{user_ip}?token=[YOUR_GEO_API_KEY]'
resp = requests.get(geo_url)
if resp.status_code != 200:
    abort(403, "Could not verify location.")

country = resp.json().get('country')
if country != 'US':
    abort(403, "Access Denied: This service is US only.")
