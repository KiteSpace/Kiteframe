================================================
TASK GROUP 1 — PRD ↔ WORKFLOW LINKING (SECTION-LEVEL ONLY)
================================================

GOAL:
Allow PRD sections to link to workflow nodes and edges, with visual indicators and canvas focus behavior.

--------------------------------
Task 1.1 — Extend Existing PRD Link Store
--------------------------------

Files to inspect:
- prdNodeLinkStore.ts (or equivalent)
- Existing PRD → Node linking logic

Instructions:
- Extend the existing store to support:
  - targetType: 'node' | 'edge'
  - Multiple targets per PRD section
- Each PRD section may link to:
  - Multiple nodes
  - Multiple edges
- DO NOT create a new TextBinding model
- DO NOT store text offsets or text ranges

Expected data shape (example):

{
  projectId,
  workflowId,
  sectionId,
  targets: [
    { type: 'node', id: nodeId },
    { type: 'edge', id: edgeId }
  ]
}

--------------------------------
Task 1.2 — PRD UI: Section-Level Linking Controls
--------------------------------

Location:
- Workflow PRD UI (Specs / Project panel)

Behavior:
- Each PRD section shows a small “Linked” indicator if links exist
- Indicator displays count (e.g. “Linked to 3 items”)
- Clicking indicator opens a simple picker:
  - List of nodes
  - List of edges
  - Allow add/remove links

UX Rules:
- Section-level only
- No text selection
- No inline toolbar
- No new editor libraries

--------------------------------
Task 1.3 — Canvas Focus on Link Click
--------------------------------

Existing:
- Node focus already works via focusBus.focusNodes()

Implement:
- Add focusBus.focusEdges(edgeIds)
- When clicking a PRD link indicator:
  - Focus all linked nodes and edges
  - Center the canvas
  - Apply temporary highlight (outline or glow)
- Clear highlight on blur or new focus
