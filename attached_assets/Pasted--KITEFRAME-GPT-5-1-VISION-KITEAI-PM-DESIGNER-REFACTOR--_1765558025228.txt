SECTION 2 — TWO‑STAGE WORKFLOW GENERATION PIPELINE
----------------------------------------------------------------

Create file:
client/src/ai/workflow/visionPipeline.ts

Export function:
generateWorkflowFromFrame({
  frameImage,
  figmaSemantic,
  projectContext,
  workflowContext
})

Pipeline rules:

Stage 1 — Heuristics (ALWAYS RUN)
• Use existing semantic extraction
• Produce SemanticFrameSummary
• Compute confidence score (0–1)

Stage 2 — Vision (CONDITIONAL)
Invoke GPT‑5.1 ONLY IF:
• confidence < 0.75
• elementsDetected > 1
• decorativeOnly !== true
• no cached vision result exists

If skipped → return heuristic workflow.
