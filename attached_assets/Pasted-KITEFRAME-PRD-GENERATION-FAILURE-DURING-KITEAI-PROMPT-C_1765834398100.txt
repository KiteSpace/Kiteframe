KITEFRAME — PRD GENERATION FAILURE DURING KITEAI PROMPT CHAT
DIAGNOSTIC QUESTIONS FOR REPLIT

GOAL
Identify why “Generate PRD” fails specifically when workflows are created via KiteAI prompt chat, while PRD generation works in other flows (toolbar, Figma, manual).

==================================================

==================================================

1. What exact code path creates workflows when initiated from KiteAI prompt chat?
   - File(s) and function(s) involved (e.g. PreProjectChat, useKiteAIConversation, createWorkflowFromAI)
   - Confirm whether this differs from:
     - Toolbar “Generate Workflow”
     - Figma/Image → Generate Workflow
     - Manual canvas workflow creation

2. Is generateWorkflowPRD() invoked anywhere in the KiteAI prompt flow?
   - If YES: where exactly?
   - If NO: what condition triggers it in other flows?

3. What event is intended to trigger PRD generation after AI workflow creation?
   - Explicit user click?

   - “Generate first draft PRD” checkbox logic?

==================================================

4. Does the AI-created workflow receive a valid workflowGroupId at creation time?

5. Are AI-created workflows marked as preview/ghost?

6. Is PRD generation blocked by workflow maturity rules?
