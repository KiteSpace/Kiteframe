Merge logic:
	•	Match issues by fingerprint
	•	Preserve:
	•	acknowledged
	•	dismissed
	•	Reset status if fingerprint disappears and later reappears

Rules
	•	Never delete resolved issues from storage immediately
	•	Resolution only occurs when detector no longer emits the fingerprint
	•	No UI coupling

Done When
	•	Diagnostics survive reloads
	•	Acknowledging an issue does not permanently suppress it if it reappears

Goal
