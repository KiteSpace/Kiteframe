REPLIT TASK FILE — KiteAI In-Project Replace/Create Still Broken (Post-Audit, Post-Implementation)

Goal
Fix the remaining critical failures observed in the attached exports:
- REPLACE still flattens workflows (loss of depth/branches) and can create “nodes without context”
- CREATE/EXTEND can fail to merge meaningfully
- REPLACE is still passing through graph-rewriting logic somewhere (normalization/repair/merge helpers) instead of “clear + insert verbatim”
- Add a structural regression guard so a branched workflow cannot be silently replaced by a flattened one

Constraints / Rules (non-negotiable)
1) REPLACE MUST be an “adoption” commit, not a mutation merge:
   - It must NOT call:
     orchestrateChatWorkflowMutation
     applyChatWorkflowMutation
     runWorkflowRepairs
     attachment resolution
     semanticKey matching
     merge/branch heuristics
     any helper that rewrites nodes/edges
2) REPLACE MUST be topology-preserving:
   - It must insert the draft nodes/edges exactly as produced (after minimal validation only)
3) REPLACE MUST be atomic and undoable:
   - One withUndo("ai-replace", ...) that sets nodes/edges/canvasObjects deterministically
4) KEEP remains removed (out of scope)
5) CREATE/EXTEND MUST NOT create disconnected islands by default:
   - If we can’t confidently attach, block and ask user where to attach (do not add floating islands)
6) Add “structural regression guard”:
   - If proposed replacement reduces branching/decision topology materially, require explicit confirmation

Deliverables
- A PR that implements the changes below
- Minimal unit tests covering REPLACE no-rewrite + regression guard
- Console logs only if dev-gated; remove or gate after verification

PHASE 3 — Add structural regression guard for REPLACE
===========================================================

Problem observed:
- Branched workflow (decision branches) can be replaced by a flattened linear workflow without warning.

3.1 Implement a “structure diff” function
File: client/src/workflow/analysis/graphStructure.ts (or similar new file)
Function: getGraphStructureStats(nodes, edges) returns:
- nodeCount
- edgeCount
- branchingPoints: count of nodes with outDegree >= 2
- decisionNodes: count of nodes whose type indicates decision/condition OR outDegree >= 2
- labeledDecisionEdges: count of edges leaving branching nodes that have non-empty labels

3.2 Compare current graph to proposed replacement
In workflow-editor.tsx (or KiteAIChat.tsx before calling onReplaceWorkflow):
- statsExisting = getGraphStructureStats(currentNodes, currentEdges)
- statsProposed = getGraphStructureStats(draft.nodes, draft.edges)

Trigger regression warning if ANY of:
- statsProposed.branchingPoints < statsExisting.branchingPoints
- statsProposed.decisionNodes < statsExisting.decisionNodes
- statsProposed.labeledDecisionEdges < statsExisting.labeledDecisionEdges

When triggered:
- Show a confirmation modal:
  “This replacement removes branches/decision paths from the current workflow. Continue?”
Buttons:
  - Continue Replace
  - Cancel

Important:
- This is separate from the full-graph replace confirmation.
- It is a “quality guard” to prevent silent flattening.
