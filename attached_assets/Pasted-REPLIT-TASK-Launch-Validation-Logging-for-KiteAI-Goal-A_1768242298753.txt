REPLIT TASK — Launch Validation Logging for KiteAI

Goal
Add minimal, structured logging + user-visible feedback so we can:
- Validate AI workflows during testing
- Distinguish AI failures from UX/system issues
- Assess perceived AI reliability without deep debugging
This must NOT introduce new AI logic or expand scope.

==================================================
NON-GOALS (DO NOT IMPLEMENT)
==================================================
- No new AI prompts or behaviors
- No diagnostics refactors
- No new modes (suggest/apply/etc.)
- No analytics dashboards
- No performance instrumentation
- No schema normalization

==================================================
SCOPE: WHAT TO IMPLEMENT
==================================================
ONLY the following:
1) One structured log per AI interaction
2) Explicit user-visible outcome messaging for AI actions
3) Minimal helpers to compute node/edge deltas
4) Dev-flag gating for logs (on by default in dev)

==================================================
PHASE 1 — Define the Log Event Shape
==================================================

Create a shared type:

File: client/src/ai/aiTelemetry.ts

```ts
export type AiInteractionLog = {
  surface: 'home' | 'project';
  phase: 'baseline' | 'edge_expand' | 'accept' | 'in_project';
  action: 'generate' | 'expand_edges' | 'apply' | 'replace';
  success: boolean;
  reason?: 'parse_fail' | 'no_change' | 'blocked' | 'user_cancel';
  nodeDelta?: number;
  edgeDelta?: number;
};
Add a helper:

ts
Copy code
export function logAiInteraction(event: AiInteractionLog) {
  if (process.env.NODE_ENV !== 'development') return;
  console.info('[AI_TELEMETRY]', event);
}
No external services. Console only.

==================================================
PHASE 2 — Add Delta Computation Helper
File: client/src/utils/workflowDiff.ts

ts
Copy code
export function computeWorkflowDelta(
  before?: { nodes: any[]; edges: any[] },
  after?: { nodes: any[]; edges: any[] }
) {
  if (!before || !after) return {};
  return {
    nodeDelta: after.nodes.length - before.nodes.length,
    edgeDelta: after.edges.length - before.edges.length,
  };
}

ts

  action: 'expand_edges',
