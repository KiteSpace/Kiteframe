Objective:
Integrate existing AI guardrail infrastructure into the actual runtime flow so AI behavior matches intended guarantees. No new logic, only wiring and UI feedback.

PHASE 1 — Baseline + Delta Enforcement

1. In KiteAIChat.tsx, before sending ANY AI proposal request:
   - Call captureDiagnosticBaseline(workflow)
   - Store result as baselineDiagnosticsRef (useRef)

2. After AI returns a proposal but BEFORE applying:
   - Call computeDiagnosticDelta(baseline, proposedWorkflow)
   - If newIssueCount > 0:
     - Reject proposal
     - Log aiStability with proposalRejected=true
     - Show toast:
       "This proposal introduced new issues and was not applied."

PHASE 2 — Fix Scope Enforcement

3. Immediately after parsing AI proposal JSON:
   - Call createFixScope(baselineWorkflow)
   - Call validateFixScope(proposal, fixScope)

4. If validation fails:
   - Do NOT apply proposal
   - Surface validation.details in UI toast
   - Log rejection reason in telemetry

PHASE 3 — Proposal Schema + Edit-First Enforcement

5. After fixScope validation:
   - Call validateProposalSchema(proposal)
   - Call validateEditFirstHeuristic(proposal)

6. If either fails:
   - Reject atomically
   - No canvas mutation
   - Show user-facing explanation

PHASE 4 — Test Flight Intent Wiring

7. When Test Flight is triggered:
   - If AI-initiated → diagnosticsMode = 'educate'
   - If user-initiated → diagnosticsMode = 'validate'

8. Ensure filterDiagnosticsByMode() is used before surfacing issues

PHASE 5 — Telemetry Wiring (Dev Only)

9. On every AI proposal attempt:
   - Emit logAiStability() with:
     - baselineIssueCount
     - postProposalIssueCount
     - newIssueCount
     - proposalRejected
     - rejectionReason (if any)

PHASE 6 — UI Feedback (Required)

10. For every rejection path:
    - Ensure user sees a clear, non-technical explanation
    - Never fail silently

Definition of Done:
- AI cannot worsen diagnostics
- AI cannot add out-of-scope structure
- AI failures are visible and explainable
- No canvas mutation occurs on rejection
