KITEFRAME — PUBLIC LANDING PAGE (PRIVATE BETA) 
FULL OVERWRITE IMPLEMENTATION SPEC FOR REPLIT

GOAL
Replace the existing non-authenticated homepage with a dedicated public landing page
that:
- Clearly communicates Kiteframe is in PRIVATE BETA
- Blocks non-beta users from accessing the Home prompt/editor
- Allows beta users to authenticate
- Allows non-beta users to join a waitlist
- Includes a live, interactive (but non-editable) Kiteframe-style workflow demo
- Uses Kiteframe UI primitives and styling (NOT React Flow branding)

IMPORTANT
This landing page DOES NOT replace the Home prompt for authenticated users.
It only applies when:
- user is not authenticated OR
- user is authenticated but not in beta allowlist

------------------------------------------------
ROUTING & ACCESS CONTROL
------------------------------------------------

1. ROUTE STRUCTURE

Add a new route:
  /
    -> PublicLandingPage (unauthenticated OR not-beta)
  /app
    -> Existing WorkflowEditor + Home prompt (authenticated + beta)

Modify routing logic in App.tsx (or equivalent router file):

PSEUDO LOGIC:
------------------------------------------------
if (!user.isAuthenticated) {
  render <PublicLandingPage />
} else if (!user.isBetaUser) {
  render <PublicLandingPage />
} else {
  render <WorkflowEditor />
}
------------------------------------------------

DO NOT mount WorkflowEditor or HomeScreen for non-beta users.

------------------------------------------------
BETA ACCESS MODEL
------------------------------------------------

2. BETA USER CHECK

Add beta access check:
- Allowlist by email
- Simple boolean flag isBetaUser

Implementation options (choose ONE for MVP):
- Hardcoded allowlist array (fastest)
- Firestore / Supabase table: beta_users(email)
- Environment variable list

REQUIRED API:
------------------------------------------------
isBetaUser(email: string): boolean
------------------------------------------------

On successful OAuth login:
- Check beta status
- If false → redirect back to PublicLandingPage with message
