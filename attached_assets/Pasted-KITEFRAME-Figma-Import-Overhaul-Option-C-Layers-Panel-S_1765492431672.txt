SECTION 0 — ARCHITECTURE GOALS (READ FIRST)
--------------------------------------------------------------------------------
This spec defines the full implementation for Figma import behavior under OPTION C:

1. Importing a **frame** → import that *single frame* as an image node.
2. Importing a **page** → user chooses:
    • A) Import page as one flattened image, OR
    • B) Import individual frames (with frame-selection grid).
3. Importing a **file** → user chooses:
    • A) Import frames individually (default), OR
    • B) Import a single page as flattened image.

Shared rules for ALL imports:
• NO automatic workflow creation ever.
• Only import frames into nodes AFTER user selects them.
• Semantic workflow generator remains manual.
• Figma imports NEVER produce orphan nodes or unintended workflows.

This spec ALSO includes:
• Layers panel project-scoping fix.
• Workflow generator clean grouping + batching behavior.

--------------------------------------------------------------------------------
SECTION 1 — DETECT FIGMA URL TYPE
--------------------------------------------------------------------------------
Modify figmaUrl.ts:

Add function:

export function detectFigmaUrlType(url: string): 'frame' | 'page' | 'file' | null

Rules:
1. If URL contains ?node-id=XXXX and node.type === FRAME → return 'frame'.
2. If URL contains ?node-id=XXXX and node.type === CANVAS (page) → return 'page'.
3. If URL has no node-id → return 'file'.
4. If URL fails → return null.
