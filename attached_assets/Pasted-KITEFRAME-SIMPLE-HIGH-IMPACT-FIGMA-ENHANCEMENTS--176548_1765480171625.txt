FEATURE 4 — PRESERVE ORDERING IN GENERATED WORKFLOWS
==================================================

SUMMARY
-------
Workflow generation should follow a predictable order using:
1. Numeric prefix in frame name (e.g., "01 Login", "02 Error")
2. Canvas X position (left to right)
3. Alphabetical name fallback

IMPLEMENTATION
--------------
Wherever `onGenerateWorkflowFromFrames(frameNodeIds)` is implemented:

STEP 1 — ADD ORDERING FUNCTION
------------------------------
Create a helper:

function sortFrameNodesForWorkflow(nodes: Node[]): Node[] {
  return nodes.slice().sort((a, b) => {
    const nameA = a.data?.label || a.data?.figmaName || '';
    const nameB = b.data?.label || b.data?.figmaName || '';

    // 1) Try numeric prefix
    const numA = parseInt(nameA.split(/[^0-9]/)[0], 10);
    const numB = parseInt(nameB.split(/[^0-9]/)[0], 10);
    const validA = !isNaN(numA);
    const validB = !isNaN(numB);

    if (validA && validB && numA !== numB) return numA - numB;

    // 2) Use x-position from node.position.x
    const xA = a.position?.x ?? 0;
    const xB = b.position?.x ?? 0;
    if (xA !== xB) return xA - xB;

    // 3) Alphabetical fallback
    return nameA.localeCompare(nameB);
  });
}

STEP 2 — APPLY ORDERING BEFORE GENERATION
-----------------------------------------
In onGenerateWorkflowFromFrames:

- Resolve nodes from nodeIds.
- Pass them through sortFrameNodesForWorkflow(nodes).
- Generate workflow steps in this order.

FEATURE 6 — UNDO WORKFLOW GENERATION
==================================================

SUMMARY
-------
Group all generated nodes/edges into a single undoable action.

TOOLS
-----
- UndoRedoManager.checkpoint()
- undoManager.batch() (if available) or equivalent

IMPLEMENTATION
--------------
In generateWorkflowFromSemantic() (or equivalent):

1. Capture checkpoint or start batch:

   const checkpoint = undoManager.checkpoint(
     getState,
     setState,
     'Before workflow generation'
   );

2. Generate nodes and edges INSIDE a grouped action:

   undoManager.execute(() => {
     // add nodes, add edges
     // use existing addNode/addEdge utilities
   }, 'Generate workflow from Figma frames');

3. Result:
   - A single Undo command removes all generated nodes/edges.
   - Existing canvas state before generation is preserved.

If batch API exists:
- Use undoManager.batch([...commands], 'Generate workflow…').

Ensure:
- This only impacts generated content, not reference frames or existing manual nodes.
