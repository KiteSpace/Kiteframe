PHASE 7 – AI CONVERSATION UNIFICATION
LOCKED REQUIREMENTS & IMPLEMENTATION INSTRUCTIONS

Purpose:
Unify AI reasoning logic across HomeScreen chat and in-project KiteAI chat using
useKiteAIConversation as the canonical conversation engine, WITHOUT changing
user-visible behavior for V1.

This is an infrastructure coherence task, not a feature expansion.

==================================================
A. CANONICAL ENGINE (LOCKED)
==================================================

useKiteAIConversation is the single source of truth for:
- Conversation state machine
- Actionability scoring
- PM depth guards
- Heuristic signal extraction
- Vision signal handling
- Clarification turn tracking
- Fast-path detection

DO NOT:
- Duplicate any of this logic in UI components
- Re-implement heuristics locally
- Create surface-specific forks of the hook

All differences between surfaces must be driven by:
- Input context
- Feature flags
- Configuration (NOT branching logic)

==================================================
B. FEATURE FLAGS (REQUIRED)
==================================================

Introduce and wire the following flags via FeatureFlagContext:

- ENABLE_UNIFIED_CONVERSATION_ENGINE
- ENABLE_PM_DEPTH_GUARDS_CHAT
- ENABLE_CLARIFICATION_LOOPS_CHAT

V1 DEFAULT VALUES (LOCKED):
- ENABLE_UNIFIED_CONVERSATION_ENGINE = ON
- ENABLE_PM_DEPTH_GUARDS_CHAT = OFF (warn/log only)
- ENABLE_CLARIFICATION_LOOPS_CHAT = OFF

No enforcement behavior may occur when flags are OFF.

==================================================
C. V1 BEHAVIOR CONSTRAINTS (NON-NEGOTIABLE)
==================================================

During Phase 7 / V1:

Actionability scoring:
- MAY be computed
- MAY be logged
- MAY be stored in snapshots
- MUST NOT affect generation, tone, ordering, or refusal

PM depth guards:
- MAY run
- MAY annotate DecisionSnapshots
- MAY surface warnings internally
- MUST NOT block actions
- MUST NOT auto-clarify
- MUST NOT interrupt chat flow

Clarification logic:
- Counters may increment
- State may track
- NO clarification prompts may be injected
- NO clarification loops may trigger

Fast paths:
- MUST NOT skip user-visible steps
- MUST NOT change control flow
