KITEFRAME — KITEAI ROLE-BASED REASONING REFACTOR
==============================================

GOAL
----
Refactor KiteAI so it reasons like a Product Manager or Product Designer (not a chatbot),
supports role switching, and avoids responding when confidence is low.

This work includes:
1. Exact system prompts (PM, Designer, Hybrid)
2. Role-based prompt selection
3. Confidence gating so AI knows when NOT to respond

SECTION 2 — ROLE SELECTION LOGIC
----------------------------------------------

Create file:

----------------------------------------------
Code:

export type KiteRole = 'pm' | 'designer' | 'hybrid';

export function selectKiteRole(context: {
  source?: 'figma' | 'workflow' | 'prd' | 'notes';
  target?: 'workflow' | 'prd';
  userIntent?: string;
}): KiteRole {
  if (context.source === 'figma' && context.target === 'workflow') {
    return 'hybrid';
  }

  if (context.target === 'prd' || context.userIntent?.includes('requirement')) {
    return 'pm';
  }

  if (context.source === 'figma' || context.userIntent?.includes('design')) {
    return 'designer';
  }

  return 'pm';
}

SECTION 3 — CONFIDENCE SCORING (ANTI-HALLUCINATION)
----------------------------------------------

Create file:

Code:
----------------------------------------------
export function computeConfidence(context: {
  nodeCount: number;
  edgeCount: number;
  hasSemanticData: boolean;
  userPromptLength: number;
}): number {
  let score = 0;

  if (context.hasSemanticData) score += 0.4;
  if (context.nodeCount >= 3) score += 0.2;
  if (context.edgeCount >= 2) score += 0.2;
  if (context.userPromptLength > 20) score += 0.2;

  return Math.min(score, 1);
}
