KITEFRAME – FIGMA IMPORT UI + FRAME SELECTION SPEC
==================================================
This spec defines the USER INTERFACE and FRONTEND LOGIC for the Figma Import system,
covering:

1. Where the feature appears (homepage + project page)
2. UI flow: OAuth vs PAT
3. File URL input + validation
4. Frame selection modal UI
5. Conversion pipeline handoff
6. Error states
7. Component structure & required functions

This spec assumes the backend OAuth/PAT system from the previous spec is implemented.

==================================================
0. CONSTRAINTS / DO NOT DO
==================================================

- DO NOT import full Figma documents automatically.
- DO NOT require the user to connect OAuth just to test the feature; PAT fallback must always work.
- DO NOT fetch Figma API from the client directly; ALWAYS use /api/figma/proxy.
- DO NOT request or store PAT beyond the open modal (never in localStorage or DB).
- DO NOT attempt to do auto-mapping of frames → nodes unless explicitly asked in the import step.

==================================================
1. WHERE THE FEATURE APPEARS
==================================================

The Figma Import feature is accessible in TWO PLACES:

A) HOMEPAGE – inside the "Prompt" container
   - This is used when creating a NEW project from a Figma file.
   - UI recommends connecting to Figma or using PAT.

B) PROJECT PAGE – inside a “Power Features” menu (Rocket icon)
   - Contains:
       • Upload Image
       • Import Figma File
       • Import Jira Ticket
       • Import Google Doc (future)
   - This imports INTO an existing project, adding nodes to the canvas.

The UI for A and B should be the same modal component,
just triggered from two locations.

==================================================
2. FIGMA IMPORT MODAL (MAIN ENTRY POINT)
==================================================

Component name: FigmaImportModal

Triggered by:
- "Import from Figma" button (homepage)
- "Import Figma File" item in Power Menu (project page)

Modal layout:

--------------------------------------------------
HEADER
  Icon: Figma logo
  Title: Import from Figma

BODY
  Section 1: Figma File URL field
  Section 2: Authentication method selection
      - Option A: Connect to Figma (OAuth)
      - Option B: Use personal access token (PAT)
  Section 3: Action button (Continue)

FOOTER
  Cancel button
--------------------------------------------------

==================================================
3. INPUT: FIGMA FILE URL
==================================================

A text input with placeholder:

  "https://www.figma.com/file/ABC123/..."

Validation rules:
- Must contain "/file/"
- Extract fileKey as the string between "/file/" and the next "/"
- Strip query params or page identifiers (optional)

If invalid, disable Continue button and show inline error:
"Please enter a valid Figma file URL."

==================================================
4. AUTHENTICATION OPTIONS (UI + LOGIC)
==================================================

Users select ONE of the following:

--------------------------------------------------
OPTION A: “Connect to Figma” (OAuth)
--------------------------------------------------

UI:
- Radio button
- Button: “Connect your Figma account”

Behavior:
1) Check GET /api/figma/status
2) If connected → show green badge: “Connected”
3) If not connected:
     - Clicking "Connect" calls GET /api/figma/auth
     - Browser redirects to OAuth page
4) After returning and modal reopened → status should show "Connected"

--------------------------------------------------
OPTION B: “Use a Personal Access Token”
--------------------------------------------------

UI:
- Radio button
- Text field: “Enter personal access token”
- Link: “How to get this”
- Small text:
  "Your token is used only in this session and never stored."

Behavior:
- PAT held ONLY in React state inside FigmaImportModal.
- Cleared on modal close.

--------------------------------------------------
RULE:
--------------------------------------------------
If user chooses OAuth but is not yet connected → show blocking message:
"Please connect your Figma account before continuing."
Disable Continue until authenticated.

If user chooses PAT but no PAT is provided → disable Continue.

==================================================
5. CONTINUE → FILE SUMMARY FETCH
==================================================

When user clicks Continue:

Call:
POST /api/figma/proxy
Body:
{
  "path": "files/<fileKey>",
  "usePat": true|false,
  "patToken": "<pat | undefined>"
}

Expected return:
{
  "name": "...",
  "document": {
    "children": [...]
  },
  "thumbnailUrl": "...",
  ...
}

IF error:
- Display inline error inside modal.
- Do not close modal.
- Allow user to change PAT or auth mode.

==================================================
6. FRAME DISCOVERY LOGIC
==================================================

From the returned JSON:

Traverse:
- document.children (Pages)
- page.children (Frames)
- frame.type === "FRAME" OR "COMPONENT" OR "INSTANCE"

Collect:
{
  id: <node.id>,
  name: <node.name>,
  pageName,
  width,
  height,
  absoluteBoundingBox,
}

Store this in an array `discoveredFrames`.

If zero frames found:
Show:
“No frames detected in this file. Please select a different file.”

==================================================
7. FRAME SELECTION MODAL
==================================================

After frame discovery, open a NEW modal:

Component: FigmaFramePicker

-----------------------------------------------
HEADER
  Title: Select frames to import

BODY
  - Left column: Frame list grouped by page
  - Right column: Frame preview panel

Frame List UI:
- Group frames by page:
    Page Name
      [ ] Frame A
      [ ] Frame B
      [ ] Frame C
- Each frame displays:
    • Frame name
    • Size: 1440×900 etc.
- Multi-select allowed.

Frame Preview:
- When user hovers a frame → load preview image lazily.
- Thumbnail fetched via:

  POST /api/figma/proxy
  path: `images/<fileKey>?ids=<frameId>&format=png`

- Render preview in right panel.

FOOTER
  “Import Selected Frames” (disabled until at least one frame selected)
  “Cancel”

==================================================
8. ON IMPORT → CONVERT FRAMES TO KITEFRAME NODES
==================================================

When user clicks “Import Selected Frames”:

Call:
POST /api/figma/proxy for each selected frame to fetch node details:
path: `files/<fileKey>/nodes?ids=<frameId>`

Processing steps:
1. For each frame:
   - Extract Figma text layers, shapes, images, interactions.
   - Convert to Kiteframe nodes based on your existing node system.
     (TextNode, ImageNode, ContainerNode, GroupNode, etc.)
2. Place nodes within the canvas using Figma's absoluteBoundingBox.
3. Create a Workflow group for the import:
   - Use pageName + frameName or user-provided name.
4. Auto-zoom to imported content.

==================================================
9. ERROR STATES & MESSAGES
==================================================

Case: OAuth connected but Figma returns 403/401
→ “Your Figma session expired. Please reconnect.”

Case: PAT invalid:
→ “Invalid personal access token. Please verify and try again.”

Case: FileKey invalid:
→ “This file cannot be accessed. Check the URL or permissions.”

Case: Unexpected server error:
→ “Something went wrong. Try again, or use a personal access token.”

==================================================
11. REQUIRED FUNCTIONS (FRONTEND)
==================================================

extractFileKey(url: string): string|null
  - Parse Figma URL and return fileKey.

callFigmaApi(path: string, opts?: { pat?: string })
  - Wrapper for POST /api/figma/proxy.
  - opts.pat overrides OAuth.

discoverFrames(fileJson)
  - Traverse Figma document to list usable frames.

loadFrameThumbnail(fileKey, frameId, pat?)
  - Calls: images/<fileKey>?ids=<frameId>&format=png

convertFigmaFrameToNodes(figmaFrameJson)
  - Convert Figma layers → Kiteframe nodes.
  - Use existing node system (DO NOT invent new architecture).

==================================================
12. CLEANUP / EDGE CASES
==================================================

- Closing modal clears PAT from memory.
- If OAuth is disconnected, show option “Reconnect Figma”.
- If FigmaImportModal is opened with a project that already has imported Figma frames:
    - Allow importing additional frames.
    - Do NOT overwrite existing ones.
