--------------------------------------------------
SECTION 2 — USAGE MODEL (INTERNAL)
--------------------------------------------------

2.1 Terminology
- "AI Units" = internal abstraction (NOT raw tokens)
- Users never see raw token counts
- Units are derived from token usage

2.2 Conversion Logic (Internal Only)
- 1 AI Unit = 500 tokens (rounded up)
- Formula:
  units = ceil(totalTokens / 500)

2.3 Complexity Multipliers
Apply AFTER unit calculation:

- GPT-4o → multiplier 1.0
- GPT-5.1 → multiplier 1.8
- Vision request → +1.5x
- Multi-frame vision → +2.0x

FinalUnits = ceil(baseUnits * multiplier)

SECTION 3 — SERVER-SIDE INSTRUMENTATION (REQUIRED)
--------------------------------------------------

3.1 Logging Requirement
For EVERY AI call (chat, workflow gen, PRD gen, vision, etc), log:

{
  userId: string
  projectId?: string
  workflowId?: string
  feature:
    | 'chat'
    | 'workflow_generation'
    | 'prd_generation'
    | 'vision_analysis'
    | 'image_upload'
    | 'project_summary'
  model: 'gpt-4o' | 'gpt-5.1'
  promptTokens: number
  completionTokens: number
  totalTokens: number
  units: number
  multiplier: number
  finalUnits: number
  costEstimateUSD: number
  createdAt: ISO timestamp
}

3.2 Storage
- Create new table / collection:
  ai_usage_events

- Index on:
  - userId
  - createdAt
  - feature
  - model
