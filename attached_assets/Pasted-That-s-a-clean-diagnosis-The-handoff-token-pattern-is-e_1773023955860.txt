That's a clean diagnosis. The handoff token pattern is exactly right. Here's the implementation:
Server-side (add to your auth routes):
js// In-memory store (swap for Redis if you scale)
const handoffTokens = new Map();

// After successful OAuth callback on .replit.app
app.get('/api/auth/callback', async (req, res) => {
  // ... your existing passport/OIDC handling ...
  await req.logIn(user); // sets connect.sid for .replit.app

  // Generate handoff token
  const token = crypto.randomBytes(32).toString('hex');
  handoffTokens.set(token, {
    user,
    expiresAt: Date.now() + 60_000 // 60 second TTL
  });

  res.redirect(`https://kiteframe.space/auth-complete?token=${token}`);
});

// New endpoint — called by kiteframe.space
app.get('/api/auth/handoff', async (req, res) => {
  const { token } = req.query;
  const entry = handoffTokens.get(token);

  if (!entry || Date.now() > entry.expiresAt) {
    return res.status(401).json({ message: 'Invalid or expired token' });
  }

  handoffTokens.delete(token); // one-time use

  await req.logIn(entry.user); // sets connect.sid for kiteframe.space ✅
  res.json({ success: true });
});
Client-side (AuthComplete.tsx):
tsuseEffect(() => {
  const params = new URLSearchParams(window.location.search);
  const token = params.get('token');

  if (token) {
    fetch(`/api/auth/handoff?token=${token}`)
      .then(r => r.json())
      .then(() => {
        // Strip token from URL, then proceed
        window.history.replaceState({}, '', '/');
        // your existing post-auth redirect
      });
  }
}, []);
A few things to make sure of:

The /api/auth/handoff endpoint needs to be on kiteframe.space (i.e. the same server, just reached via the custom domain) so req.logIn sets the cookie for the right domain
Add a cleanup interval to purge expired tokens from the Map in case they're never redeemed: setInterval(() => handoffTokens.forEach((v, k) => v.expiresAt < Date.now() && handoffTokens.delete(k)), 60_000)
Make sure your OAuth callback URL registered with Replit still points to .replit.app — that part doesn't change
