V1 STABILIZATION TASK — MERGE-SAFE CHAT WORKFLOW MUTATION
STATUS: REQUIRED BEFORE LAUNCH
SCOPE: ENFORCEMENT + WIRING ONLY (NO NEW UX, NO PROMPT CHANGES)

GOAL
Prevent orphan nodes, disconnected workflows, and invalid decision states when
users modify workflows via chat (both Home and In-Project chat).

All chat-driven workflow changes MUST:
• Modify the existing workflow when intent is merge
• Never create disconnected islands
• Never bypass Decision Repair
• Never reach Test Flight in an invalid state

────────────────────────────────────────
LOCKED CONSTRAINTS (DO NOT VIOLATE)
────────────────────────────────────────
• Do NOT change prompts
• Do NOT add new node types
• Do NOT add UI
• Do NOT auto-create parallel workflows
• Do NOT add new heuristics
• Do NOT allow chat to write directly to canvas state
• This is NOT a behavior change — only enforcement

────────────────────────────────────────
REQUIRED INTEGRATION ORDER
────────────────────────────────────────
Chat input
→ Merge vs Branch intent detection
→ Merge-Safe Workflow Mutation (MANDATORY)
→ Decision Repair (MANDATORY)
→ Loop Detection (warn-only)
→ Test Flight / Diagnostics

Decision Repair MUST always run before Test Flight.

────────────────────────────────────────
TASK 1 — ENFORCE MERGE-SAFE MUTATION IN PROJECT CHAT
────────────────────────────────────────
Files:
• KiteAITab
• useKiteAIConversation
• Any function calling:
  - generateWorkflowFromChat
  - applyChatWorkflowMutation
  - setNodes / setEdges

Actions:
1. Replace ALL direct canvas mutations from chat with:
   applyMergeSafeWorkflowMutation()

2. Remove any remaining:
   setNodes()
   setEdges()
   calls from chat paths

3. If applyMergeSafeWorkflowMutation() returns:
   success === false
   → DO NOT MODIFY CANVAS

4. Surface failure only via:
   DecisionSnapshot.unresolvedConcerns
   (NO UI, NO TOASTS)

HARD RULE:
Chat is NEVER allowed to write to canvas without passing merge-safe validation.

────────────────────────────────────────
TASK 2 — ENFORCE MERGE-SAFE MUTATION IN HOME / PROMPT CHAT
────────────────────────────────────────
Files:
• HomeScreen
• FullScreenChat
• Initial workflow generation logic

Rules:
• First generation with no workflow → allowed to create new workflow
• ANY follow-up referring to:
  “this workflow”, “the flow”, “add”, “fix”, “extend”
  → MUST use merge-safe mutation

Actions:
1. Detect if a workflow already exists
2. If yes → route through applyMergeSafeWorkflowMutation()
3. Branch intent required to create a second workflow

────────────────────────────────────────
TASK 3 — MERGE VS BRANCH INTENT ENFORCEMENT
────────────────────────────────────────
Ensure detectMergeBranchIntent() is called BEFORE mutation.

Rules:
• MERGE intent → modify existing workflow only
• BRANCH intent → explicitly create parallel workflow
• Ambiguous → default to MERGE

Chat MUST NOT silently branch.

────────────────────────────────────────
TASK 4 — DECISION REPAIR AS A HARD GATE
────────────────────────────────────────
Decision Repair MUST run:
• After merge-safe mutation
• Before Test Flight
• Before Propose / Experiment

Decision Repair guarantees:
• Every decision node has ≥ 2 outgoing edges
• Every decision edge has a semantic label (Yes/No, Pass/Fail, etc.)
• No dangling decision edges
• Reuse existing nodes where possible
• Create at most ONE fallback node if unavoidable

Repaired issues MUST:
• Be removed from Test Flight suggestions
• Be recorded in DecisionSnapshot.decisionRepairs

────────────────────────────────────────
TASK 5 — LOOP DETECTION (WARN-ONLY)
────────────────────────────────────────
Ensure detectLoops():
• Never blocks
• Never mutates
• Never triggers Propose / Experiment
• Only emits warnings

Warnings must appear in:
• Test Flight diagnostics
• Why Inspector
• Audit export

────────────────────────────────────────
TASK 6 — FAILURE BEHAVIOR GUARANTEE
────────────────────────────────────────
If merge-safe mutation fails:
• Canvas remains unchanged
• No partial nodes added
• No floating nodes
• Failure recorded in DecisionSnapshot
• No retries without user action

────────────────────────────────────────
TASK 7 — FINAL VERIFICATION (REQUIRED)
────────────────────────────────────────
Replit must verify YES to all:

Merge Safety:
□ Chat can NEVER add orphan nodes
□ Chat can NEVER create disconnected islands
□ Chat can NEVER bypass Decision Repair

Decision Integrity:
□ No decision reaches Test Flight with <2 labeled branches
□ Decision Repair is idempotent
□ Repaired issues never reappear as suggestions

Chat Consistency:
□ Home chat and Project chat share same mutation path
□ Follow-ups always modify existing workflow
□ Parallel workflows only created via explicit branch intent

Failure Handling:
□ Canvas unchanged on mutation failure
□ Failure captured in DecisionSnapshot
□ Visible in Why Inspector / Audit Export

DELIVERABLE
