KITEFRAME — FINAL HOME PROMPT → FULL-SCREEN CHAT FIX (BLOCKING)

ROOT PROBLEM
Home Prompt currently navigates to /app (workflow-editor), which immediately
creates a project context and routes the conversation into the Project Panel chat.

This is incorrect.

Home Prompt must expand into a FULL-SCREEN CHAT with NO project context.
Project creation must ONLY occur when the user explicitly clicks “Create Workflow”.

---------------------------------------------------------------------

NON-NEGOTIABLE RULES

1. Home Prompt submission MUST NEVER:
   - create a project
   - create a projectId
   - create a workflow tab
   - navigate to workflow-editor
   - show the project panel or canvas

2. Project creation may ONLY happen when the user clicks “Create Workflow”.

---------------------------------------------------------------------

REQUIRED ARCHITECTURE

Split the chat experience into TWO containers:

A) FullScreenChat (NEW)
   - Route: /chat
   - No projectId
   - No canvas
   - No project panel
   - Full-screen chat only
   - Uses the SAME KiteAIChat logic
   - Owns currentWorkflowDraft until Create Workflow is clicked

B) ProjectChat (EXISTING)
   - Route: /app (workflow-editor)
   - Requires projectId
   - Shows canvas and project panel
   - Used ONLY after Create Workflow

---------------------------------------------------------------------

REQUIRED FLOW

1. Home Prompt Submit
   - Navigate to /chat
   - Inject prompt into FullScreenChat
   - Conversation continues inline
   - NO project is created

2. Create Workflow (inside FullScreenChat)
   - Create project
   - Create workflow tab
   - Navigate to /app
   - Load ProjectChat with the created workflow

This is the ONLY place project creation is allowed.

---------------------------------------------------------------------

REQUIRED CODE CHANGES (EXPLICIT)

1. Add /chat route
   - Renders FullScreenChat
   - No workflow-editor, no canvas, no panel

2. Modify Home Prompt
   - Navigate to /chat?prompt=...
   - DO NOT navigate to /app
   - DO NOT create project context

3. Ensure FullScreenChat
   - Reuses KiteAIChat logic
   - Uses currentWorkflowDraft
   - Renders WorkflowDraftActions
   - Has Create Workflow button

4. Modify Create Workflow handler
   - Create project
   - Navigate to /app
   - Initialize ProjectChat state

---------------------------------------------------------------------

ACCEPTANCE CRITERIA (PASS / FAIL)

PASS if:
- Home Prompt opens a full-screen chat
- No project is created
- No project panel or canvas is visible
- Chat continues inline

PASS if:
- Clicking Create Workflow THEN creates a project
- User is routed into workflow-editor at that moment

FAIL if:
- Any project is created on Home Prompt submission
- Chat appears inside the Project Panel immediately
- workflow-editor loads before Create Workflow

Do not patch around it.
