KITEFRAME — EXPERIMENT NODE v1
UX + AI WORKFLOW IMPLEMENTATION SPEC
===================================

OVERVIEW
--------
The Experiment node is a speculative workflow tool that allows users to explore alternate paths, risks, enhancements, or custom branches without committing changes.

Experiment nodes:
- Are speculative by default
- Generate preview-only branches
- Require explicit Adopt or Discard actions
- Must never pollute PRDs, exports, or maturity scoring unless adopted

--------------------------------------------------
GLOBAL RULES (APPLY TO ALL EXPERIMENT NODES)
--------------------------------------------------

1. Node Identity
- node.type = "experiment"
- node.data.speculative = true

2. Speculative Behavior
- Speculative nodes and generated branches:
  - MUST NOT appear in PRDs
  - MUST NOT affect workflow maturity
  - MUST NOT be included in exports
  - MUST be visually distinct (dashed border or muted styling)

3. AI Invocation
- AI MUST NEVER run automatically
- AI ONLY runs when user clicks "Generate Branch"

4. Preview Branch Rules
- All AI-generated nodes must include:
  meta.preview = true
  meta.source = "experiment"
  meta.experimentId = <origin experiment node id>

5. Commit Control
- Generated branches MUST require explicit Adopt or Discard
- No auto-commit behavior allowed

--------------------------------------------------
SHARED NODE UI STRUCTURE
--------------------------------------------------

Header:
- Title: "Experiment"
- Mode selector dropdown with options:
  - What If
  - Risk
  - Enhancement
  - Prompt

Body:
- Mode-specific content (recommendations or prompt input)
- Instructional microcopy

Footer:
- Primary button: Generate Branch
- Secondary buttons (only after generation):
  - Adopt
  - Discard

--------------------------------------------------
MODE 1: WHAT IF
--------------------------------------------------

Purpose:
Explore edge cases or alternate paths from the current workflow step.

UX FLOW:
- Default mode on node creation
- Show 3–5 pre-populated "What if" suggestions
- No text input visible initially

UI Copy:
"What might change or diverge at this point?"

RECOMMENDATIONS:
- Render selectable list items such as:
  - What if this step requires re-approval?
  - What if requirements are incomplete here?
  - What if this loops back due to stakeholder feedback?

Rules:
- Only ONE recommendation may be selected
- Selecting a recommendation clears any custom input

FREE-FORM ESCAPE:
- Below list: "Or describe a custom scenario..."
- Clicking reveals text input
- Typing clears recommendation selection

GENERATE BRANCH:
On click:
1. Validate input exists (recommendation OR text)
2. Build AI context:
   {
     mode: "whatif",
     anchorNodeId,
     experimentText,
     upstreamNodes,
     downstreamNodes,
     fullWorkflowContext,
     speculative: true
   }
3. Invoke AI branch generation

AI OUTPUT REQUIREMENTS:
- At least 2 nodes
- At least 1 decision or loop-back
- All nodes marked:
  meta.preview = true
  meta.experimentType = "whatif"

--------------------------------------------------
MODE 2: RISK
--------------------------------------------------

Purpose:
Explore risks relevant to the current workflow stage.

UX FLOW:
- Show categorized risk suggestions
- No free-form input initially

UI Copy:
"Potential risks at this stage"

RISK OPTIONS:
Examples:
- Ownership unclear
- Missing decision authority
- Misaligned stakeholder expectations

Rules:
- User must select ONE risk to proceed

OPTIONAL CUSTOM RISK:
- "Add a custom risk..."
- Behaves like What If free-form

GENERATE BRANCH:
AI context:
{
  mode: "risk",
  riskType,
  anchorNodeId,
  workflowStage,
  fullWorkflowContext,
  speculative: true
}

AI OUTPUT:
- Risk realization path
- Consequence step
- Optional mitigation branch
- Preview-only nodes

--------------------------------------------------
MODE 3: ENHANCEMENT
--------------------------------------------------

Purpose:
Improve efficiency, quality, or speed of workflow.

UX FLOW:
- Show enhancement recommendations
- Hide free-form initially

UI Copy:
"Ways this step could be improved"

EXAMPLES:
- Replace meetings with async review
- Add AI-generated artifact
- Automate validation step

FREE-FORM OPTION:
- Same behavior as other modes

GENERATE BRANCH:
AI context:
{
  mode: "enhancement",
  enhancementIdea,
  anchorNodeId,
  optimizationGoal,
  fullWorkflowContext,
  speculative: true
}

AI OUTPUT:
- Enhanced alternative path
- Clear before/after contrast
- Original path remains untouched

--------------------------------------------------
MODE 4: PROMPT
--------------------------------------------------

Purpose:
Advanced, fully custom branch generation.

UX FLOW:
- Hide recommendations
- Show text input immediately

UI Copy:
"Describe the branch you want to explore"

RULES:
- Text input REQUIRED
- No auto-suggestions

GENERATE BRANCH:
AI context:
{
  mode: "prompt",
  userPrompt,
  anchorNodeId,
  fullWorkflowContext,
  speculative: true
}

--------------------------------------------------
ADOPT / DISCARD LOGIC (ALL MODES)
--------------------------------------------------

DISCARD:
- Remove generated nodes and edges
- DO NOT add undo history entry
- Reset experiment node state:
  hasGeneratedBranch = false
  generatedIds = []

ADOPT:
- Remove meta.preview flags
- Convert nodes to standard workflow nodes
- Add ONE undo entry labeled:
  "Adopt experiment branch"

--------------------------------------------------
ERROR HANDLING
--------------------------------------------------

AI Failure:
- Show inline error message
- Preserve user input
- Allow retry

Partial Generation:
- Auto-discard
- Notify user

--------------------------------------------------
EXPLICIT NON-GOALS (V1)
--------------------------------------------------

- No ghost-only nodes
- No multi-branch comparison
- No risk scoring
- No cost/time simulation
- No persistent risk library
- No collaboration conflict resolution
