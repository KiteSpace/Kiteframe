3. BATCHED FIGMA NODE FETCHING (REQUIRED)
=========================================
Existing behavior:
  One request per frame → ❌ inefficient, risks rate limiting

New behavior:
  Use: files/:fileKey/nodes?ids=id1,id2,id3,...

Implementation:

In figmaApi.ts, add:

export async function fetchFigmaFrameTrees(fileKey: string, frameIds: string[], pat?: string) {
  const idsParam = frameIds.join(",");
  const res = await fetch("/api/figma/proxy", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      path: `files/${fileKey}/nodes?ids=${idsParam}`,
      usePat: !!pat,
      patToken: pat ?? null,
    }),
  });

  if (!res.ok) throw new Error(`Failed to fetch Figma nodes`);
  const json = await res.json();
  return json.nodes;
}

Important:
- Replit should NOT change the /api/figma/proxy backend.
- Token routing (OAuth session tokens vs PAT) is already handled.

4. EXTRACTION LIMITS (REQUIRED FOR PERFORMANCE)
===============================================
In figmaSemanticExtractor.ts:

Apply both limits:

MAX_DEPTH = 10  
MAX_ELEMENTS = 500  

Stop traversal when either limit is hit:

if (depth > MAX_DEPTH || elementCount >= MAX_ELEMENTS) return;

Reason:
Prevents runaway recursion on large files.

5. IMPROVED HEURISTICS (REQUIRED)
=================================
Replit should update heuristics to include:

a) COMPONENT or INSTANCE with variant names:
   - Check node.componentProperties
   - Check node.mainComponent name patterns for buttons/inputs

b) Text inside parent:
   - If a FRAME/GROUP contains exactly one TEXT child → classify as button-like

c) Default fallbacks:
   - If nothing matches, classify as 'section' only if appropriate
   - Otherwise skip element creation

d) Internationalization-safe rules:
   - Do NOT rely solely on English keyword heuristics
   - Use structure-based rules (shape + text)

============================

- The node tree fetch fails, OR
- The semantic extractor throws, OR
- Traversal exceeds limits

Then:
- Import the image node anyway
- Set figmaSemantic = null

DO NOT block project creation.
DO NOT display alert popups.
DO NOT show errors to users.

7. APPLY SEMANTICS IN convertFigmaToNodes.ts (REQUIRED)
=======================================================
Replace per-frame fetching with a batched call:

const nodesJson = await fetchFigmaFrameTrees(fileKey, selectedFrameIds, pat);

Then for each frame in frames:

const frameNode = nodesJson[frame.id]?.document;
if (!frameNode) {
  imageNode.data.figmaSemantic = null; // fallback
} else {
  try {
    const semantic = extractFigmaSemanticMetadata(frameNode, frame.pageName);
    imageNode.data.figmaSemantic = semantic;
  } catch {
    imageNode.data.figmaSemantic = null;
  }
}
