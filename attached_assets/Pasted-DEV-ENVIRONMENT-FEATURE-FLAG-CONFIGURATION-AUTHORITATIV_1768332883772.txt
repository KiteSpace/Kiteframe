========================================
NON-NEGOTIABLE DEV REQUIREMENTS
========================================

1. FLAG_AI_STABILIZATION MUST be ON in dev.
2. Any AI rejection MUST:
   - Show user-visible feedback
   - Emit telemetry
3. No AI proposal may mutate canvas if rejected.
4. Test Flight in dev must support BOTH:
   - validate mode (full diagnostics)
   - educate mode (blockers only)
5. Telemetry logs MUST be visible in console in dev.

========================================
DEFINITION OF DEV-READY
========================================

Dev environment is considered correctly configured when:
- AI cannot worsen workflows
- All guardrails are actively exercised
- Rejections are explainable
- No silent failures occur
