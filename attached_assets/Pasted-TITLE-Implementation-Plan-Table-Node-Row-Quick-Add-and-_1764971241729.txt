TITLE: Implementation Plan – Table Node, Row Quick-Add, and Data-Backed Nodes (Replit Instructions)

GOAL
Implement:
1) A “Table Node” type that can display imported CSV/JSON as a preview and open a floating table panel.
2) A “Data-Backed Node” created via a quick-add (+) button on table rows, with its content populated from that row.
3) A basic data-binding mechanism so nodes stay linked to their source table row.
4) A soft row limit (25 rows for row→node actions, 50 visible max) to avoid performance issues.

ASSUMPTIONS
- Frontend uses React + TypeScript.
- Canvas is powered by React Flow (or similar node/edge graph library).
- There is an existing node system with:
  - A `nodeTypes` map registering custom node components.
  - A state container for the graph (React Flow hooks, Redux, Zustand, or similar).
- There is an existing pattern for:
  - Floating panels (e.g., AI chat panel, layers panel).
  - Node selection, property panels, and node toolbars.
- Persistence (if needed) uses the existing graph serialization (e.g., saving nodes/edges to JSON).

If any assumption is wrong, adapt paths and state handling to match the actual project structure.

2.2 Implement TableNode as a React Flow node component

Create `src/nodes/TableNode/TableNode.tsx`:

Responsibilities:
- Render:
  - Header: icon + table name.
  - A small preview grid of first 3–4 rows.
  - Footer with “▶ Open Table” and a ⋮ menu.
- Handle selection and show the node’s standard toolbar (leveraging existing node chrome).
- On “Open Table” click → open the floating `TablePanel` with this table ID.

Key props:
- `data.tableId` – ID used to look up the DataTable in the store.

Minimal structure:

----------------------------------------
import { memo } from "react";
import { Handle, Position, NodeProps } from "reactflow";
import { useGraphStore } from "../../state/graphStore";

const MAX_PREVIEW_ROWS = 3;
const MAX_PREVIEW_COLUMNS = 4;

function TableNodeComponent(props: NodeProps) {
  const { id, data, selected } = props;
  const tableId = data.tableId as string;
  const { dataTables, openTablePanelById } = useGraphStore(); // implement openTablePanelById in store
  const table = dataTables[tableId];

  if (!table) {
    return (
      <div className="table-node-missing">
        Missing table
      </div>
    );
  }

  const { name, columns, rows } = table;
  const previewColumns = columns.slice(0, MAX_PREVIEW_COLUMNS);
  const previewRows = rows.slice(0, MAX_PREVIEW_ROWS);

  return (
    <div className={`kf-node kf-table-node ${selected ? "is-selected" : ""}`}>
      {/* header */}
      <div className="kf-table-node__header">
        <span className="kf-table-node__icon">📄</span>
        <span className="kf-table-node__title">{name}</span>
      </div>

      {/* preview */}
      <div className="kf-table-node__preview">
        <div className="kf-table-node__preview-header-row">
          {previewColumns.map((col) => (
            <div key={col.id} className="kf-table-node__cell kf-table-node__cell--header">
              {col.name}
            </div>
          ))}
        </div>
        {previewRows.map((row) => (
          <div key={row.id} className="kf-table-node__preview-row">
            {previewColumns.map((col) => (
              <div key={col.id} className="kf-table-node__cell">
                {String(row.values[col.id] ?? "")}
              </div>
            ))}
          </div>
        ))}
      </div>

      {/* footer */}
      <div className="kf-table-node__footer">
        <button
          className="kf-table-node__open-button"
          onClick={() => openTablePanelById(tableId)}
        >
          ▶ Open Table
        </button>
        <button className="kf-table-node__more-button">⋮</button>
      </div>

      {/* optional handles */}
      <Handle type="source" position={Position.Right} />
      <Handle type="target" position={Position.Left} />
    </div>
  );
}

export default memo(TableNodeComponent);
----------------------------------------

3.2 Implement TablePanel UI

`src/panels/TablePanel/TablePanel.tsx`:

Responsibilities:
- Draggable floating panel (use any existing “floating panel” component).
- Show full table (up to row limit).
- Show row-hover + quick-add (+) button for each allowed row.
- Show row limit messaging.

----------------------------------------
import React from "react";
import { useGraphStore } from "../../state/graphStore";
import { useTablePanelStore } from "./tablePanelStore";

const MAX_VISIBLE_ROWS = 50;
const MAX_ROW_TO_NODE = 25;

const TablePanel: React.FC = () => {
  const { openTableId, closeTablePanel } = useTablePanelStore();
  const { dataTables, createNodeFromTableRow } = useGraphStore();

  if (!openTableId) return null;

  const table = dataTables[openTableId];
  if (!table) return null;

  const { name, columns, rows, meta } = table;

  const visibleRows = rows.slice(0, MAX_VISIBLE_ROWS);
  const canCreateFromRow = (index: number) => index < MAX_ROW_TO_NODE;

  return (
    <div className="kf-floating-panel kf-table-panel">
      <div className="kf-floating-panel__header" /* make draggable if you have that util */>
        <span>📄 {name}</span>
        <button onClick={closeTablePanel}>✕</button>
      </div>

      <div className="kf-table-panel__toolbar">
        <button>Import CSV / JSON</button>
        <span>
          Showing {visibleRows.length} of {(meta?.totalRowCount ?? rows.length)} rows
        </span>
      </div>

      <div className="kf-table-panel__table">
        <div className="kf-table-panel__header-row">
          {columns.map((col) => (
            <div key={col.id} className="kf-table-panel__cell kf-table-panel__cell--header">
              {col.name}
            </div>
          ))}
          <div className="kf-table-panel__cell kf-table-panel__cell--header kf-table-panel__cell--actions" />
        </div>

        {visibleRows.map((row, rowIndex) => (
          <div key={row.id} className="kf-table-panel__row">
            {columns.map((col) => (
              <div key={col.id} className="kf-table-panel__cell">
                {String(row.values[col.id] ?? "")}
              </div>
            ))}
            <div className="kf-table-panel__cell kf-table-panel__cell--actions">
              {canCreateFromRow(rowIndex) && (
                <button
                  className="kf-table-panel__quick-add"
                  onClick={() =>
                    createNodeFromTableRow({
                      tableId: table.id,
                      rowId: row.id,
                    })
                  }
                  title="Create node from this row"
                >
                  +
                </button>
              )}
            </div>
          </div>
        ))}
      </div>

      {rows.length > MAX_ROW_TO_NODE && (
        <div className="kf-table-panel__note">
          Row-to-node creation is limited to the first {MAX_ROW_TO_NODE} rows for performance.
        </div>
      )}
    </div>
  );
};

export default TablePanel;
----------------------------------------

5.2 Implement the DataBackedNode React component

`src/nodes/DataBackedNode/DataBackedNode.tsx`:

Requirements:
- Title = the “primary” column’s value.
- Body = up to 4–6 key/value lines (e.g., `Layer: Presentation`).
- Show a small “linked” icon to indicate it’s bound to a table row.
- Use `data.rowBinding` or `data.tableId` + `data.rowId`.

Example:

----------------------------------------
import { memo, useMemo } from "react";
import { NodeProps } from "reactflow";
import { useGraphStore } from "../../state/graphStore";

const MAX_FIELDS_IN_BODY = 4;

function DataBackedNodeComponent(props: NodeProps) {
  const { id, data, selected } = props;
  const { dataTables } = useGraphStore();
  const tableId = data.tableId as string;
  const rowId = data.rowId as string;
  const table = dataTables[tableId];

  const { title, fields } = useMemo(() => {
    if (!table) return { title: "Missing table", fields: [] as { key: string; value: string }[] };
    const { columns, rows, meta } = table;
    const row = rows.find((r) => r.id === rowId);
    if (!row) return { title: "Missing row", fields: [] };

    const primaryColumnId = meta?.primaryColumnId ?? columns[0]?.id;
    const primaryColumn = columns.find((c) => c.id === primaryColumnId);
    const titleValue = primaryColumn ? row.values[primaryColumn.id] : row.id;

    const fieldPairs: { key: string; value: string }[] = [];
    for (const col of columns) {
      if (!row.values.hasOwnProperty(col.id)) continue;
      if (col.id === primaryColumnId) continue; // skip title column in body
      const raw = row.values[col.id];
      if (raw === null || raw === undefined || raw === "") continue;
      fieldPairs.push({ key: col.name, value: String(raw) });
    }

    return {
      title: String(titleValue ?? "Untitled"),
      fields: fieldPairs.slice(0, MAX_FIELDS_IN_BODY),
    };
  }, [tableId, rowId, dataTables]);

  return (
    <div className={`kf-node kf-data-backed-node ${selected ? "is-selected" : ""}`}>
      <div className="kf-data-backed-node__header">
        <span className="kf-data-backed-node__title">{title}</span>
        <span className="kf-data-backed-node__link-icon" title="Linked to table row">
          🔗
        </span>
      </div>
      <div className="kf-data-backed-node__body">
        {fields.map((f) => (
          <div key={f.key} className="kf-data-backed-node__field">
            <span className="kf-data-backed-node__field-key">{f.key}: </span>
            <span className="kf-data-backed-node__field-value">{f.value}</span>
          </div>
        ))}
      </div>
    </div>
  );
}

export default memo(DataBackedNodeComponent);

- Add a row binding object if you want to track relationships explicitly.

Example (pseudo-code, adapt to your store):

----------------------------------------
type CreateNodeFromRowArgs = {
  tableId: string;
  rowId: string;
};

createNodeFromTableRow: (args: CreateNodeFromRowArgs) => void;
----------------------------------------

Implementation sketch:

----------------------------------------
createNodeFromTableRow: ({ tableId, rowId }) =>
  set((state) => {
    const tableNode = state.nodes.find(
      (n) => n.type === "tableNode" && n.data?.tableId === tableId
    );
    const basePosition = tableNode?.position ?? { x: 0, y: 0 };

    const newNodeId = `dataNode_${Date.now()}`;
    const newNode: Node = {
      id: newNodeId,
      type: "dataBackedNode",
      position: {
        x: basePosition.x + 280, // offset to the right
        y: basePosition.y + 40,  // slight vertical offset
      },
      data: {
        tableId,
        rowId,
      },
    };

    return {
      nodes: [...state.nodes, newNode],
      // optionally add a linking edge TableNode -> DataBackedNode
      edges: tableNode
        ? [
            ...state.edges,
            {
              id: `edge_${tableNode.id}_${newNodeId}`,
              source: tableNode.id,
              target: newNodeId,
              type: "smoothstep",
            },
          ]
        : state.edges,
      // optionally track row binding
      dataBindings: {
        ...state.dataBindings,
        rowBindings: [
          ...(state.dataBindings?.rowBindings ?? []),
          {
            type: "tableRow",
            tableId,
            rowId,
          },
        ],
      },
    };
  });
----------------------------------------

This function is called by the `TablePanel` quick-add button for each row.

STEP 7 – ROW LIMIT ENFORCEMENT
────────────────────────────────────────

We want:
- Hard display limit: 50 visible rows.
- Soft row-to-node limit: 25 rows can spawn nodes.

Enforce this in:
- TablePanel → `visibleRows = rows.slice(0, MAX_VISIBLE_ROWS)`.
- Quick-add button → `rowIndex < MAX_ROW_TO_NODE` → show +, else hide or disable.
- Note at bottom of TablePanel: “Row-to-node creation is limited to the first 25 rows for performance.”

You can also:
- Store full row count in `meta.totalRowCount`.
- On import, if source rows > 50, just truncate `rows` but keep `meta.totalRowCount`.
