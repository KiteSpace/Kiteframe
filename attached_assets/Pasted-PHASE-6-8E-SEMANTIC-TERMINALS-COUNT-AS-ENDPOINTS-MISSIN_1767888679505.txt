PHASE 6.8E — SEMANTIC TERMINALS COUNT AS ENDPOINTS (MISSING END STATE FIX)
GOAL: Make detectMissingEndState() consistent with Phase 6.8 dead-end suppression.
SCOPE: Diagnostics-only. No graph mutations. Feature-flag gated.

────────────────────────────────────────────────────────
LOCKED CONSTRAINTS
────────────────────────────────────────────────────────
1) NO GRAPH MUTATION
   - Do not change node types
   - Do not add/remove nodes/edges

2) DO NOT RELAX RULES BEYOND HIGH CONFIDENCE
   - Only HIGH-confidence semantic terminals can satisfy missing end state
   - MEDIUM confidence must NOT satisfy missing end state

3) MUST REMAIN FEATURE-FLAGGED
   - Gate behind existing VITE_ENABLE_SEMANTIC_TERMINAL_INFERENCE
   - If flag OFF, behavior must be identical to current baseline

4) MUST BE EXPLAINABLE
   - If missing end state is suppressed due to semantic terminals, record why

────────────────────────────────────────────────────────
TASK 1 — ADD “HAS VALID ENDPOINT” HELPER
────────────────────────────────────────────────────────
File:
  client/src/lib/kiteframe/utils/diagnostics/DiagnosticsEngine.ts

Create helper:
  function hasValidEndpoint(args: {
    nodes: Node[];
    edges: Edge[];
    nodesById: Map<string, Node>;
  }): {
    hasEndpoint: boolean;
    semanticEndpoints?: Array<{
      nodeId: string;
      reasons: string[];
      matchedRules: string[];
    }>;
  }

Logic:
A) First check explicit terminals:
   if nodes.some(isTerminalNode) → hasEndpoint=true

B) If flag OFF:
   return hasEndpoint (do not compute semantic endpoints)

C) If flag ON:
   Evaluate semantic terminals for leaf nodes only:
   - leaf = outgoing.length === 0 && incoming.length > 0
   - node.type NOT in ['output','end']
   - call detectTerminalIntent()
   - only accept confidence === 'high'

If ANY high-confidence semantic terminal exists:
   hasEndpoint=true
   return semanticEndpoints list for audit/debug

Else:
   hasEndpoint=false

────────────────────────────────────────────────────────
TASK 2 — UPDATE detectMissingEndState() TO USE HELPER
────────────────────────────────────────────────────────
Current:
  const hasTerminal = nodes.some(isTerminalNode)
  if (!hasTerminal) emit missing-end-state

Replace with:
  const endpointResult = hasValidEndpoint(...)
  if (!endpointResult.hasEndpoint) emit missing-end-state
  else do NOT emit missing-end-state

Important:
- Do not suppress missing-end-state unless endpointResult.hasEndpoint is true
