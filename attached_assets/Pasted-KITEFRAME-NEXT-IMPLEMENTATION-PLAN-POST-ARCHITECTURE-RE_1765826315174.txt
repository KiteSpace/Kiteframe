PHASE 0 — FOUNDATIONAL GUARANTEE (REQUIRED FIRST)
================================================================

0.1 Enforce Undo / Redo Consistency (NO REWRITE)

Problem:
Undo/redo currently works by convention. Some mutations bypass saveToHistory(), risking regressions as features expand.

Do NOT rewrite UndoRedoManager.
Do NOT replace snapshot-based history.

Action:
Introduce a small helper and enforce usage everywhere state mutates.

Add helper (location flexible, e.g. workflow-editor utils):

function withUndo(label: string, fn: () => void) {
  saveToHistory(label);
  fn();
}

Rules:
- Any mutation of nodes, edges, canvasObjects, themes, layout, or bulk actions MUST be wrapped in withUndo().
- Selection state is exempt (UI-only).

Audit & update mutation sites:
- WorkflowHeader actions
- FloatingToolbar layout handlers
- Theme changes
- Bulk operations (select all, delete, drag-all)
- Any direct setNodes / setEdges mapping

Outcome:
Undo becomes reliable and future-proof without architectural changes.

---------------------------------------------------------------
1.1 Drag Entire Workflow ("Drag All")
---------------------------------------------------------------

Goal:
Allow users to reposition an entire workflow group intuitively.

Implementation:
- Use the existing GripVertical icon as drag handle
- On mousedown:
  - Capture mouse origin
  - Capture initial positions of all flowNodes
- On mousemove:
  - Apply delta to all nodes in the workflow
- On mouseup:
  - Call withUndo("Drag workflow", ...)

Notes:
- Node positions remain absolute (no group container)
- Cursor states: grab → grabbing
- Tooltip: "Drag workflow"

---------------------------------------------------------------
1.2 Select All (Workflow-Scoped)
---------------------------------------------------------------

Goal:
Select all nodes + edges belonging to the workflow.

Implementation:
- On "Select All":
  - Select all nodes in flowNodes
  - Select all edges where source AND target are in flowNodes
- Selection state already exists in workflow-editor.tsx

---------------------------------------------------------------
1.3 Delete Workflow (Explicit Action)
---------------------------------------------------------------

Goal:
Make workflow deletion explicit and understandable.

Add to WorkflowHeader dropdown:
- Label: "Delete workflow"

Behavior:
- Confirm dialog:
  "Delete this workflow and all its nodes?"
- On confirm:
  - Remove all flowNodes
  - Edge cleanup already handled
  - Wrap in withUndo("Delete workflow", ...)

Undoable: YES
