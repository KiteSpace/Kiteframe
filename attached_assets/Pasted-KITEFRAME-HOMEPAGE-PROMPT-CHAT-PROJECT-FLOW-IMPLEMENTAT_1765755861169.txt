KITEFRAME — HOMEPAGE PROMPT → CHAT → PROJECT FLOW
IMPLEMENTATION INSTRUCTIONS (FINAL)

GOAL
Remove modal interruptions and unify homepage prompt, attachments, and chat
into a single, ChatGPT-like pre-project flow that:
- Lets users attach context first (Figma, image, document)
- Shows inline previews (200px, expandable)
- Allows optional clarification chat
- Requires explicit confirmation before project creation
- Optionally auto-generates first-draft PRD after workflow creation

--------------------------------------------------
SECTION 1 — PROMPT STATE & TRANSITION REFACTOR
--------------------------------------------------

CURRENT STATE (CONFIRMED)
- HomeHero owns PromptContext (textInput + attachments)
- PreProjectChat remounts and receives context via props
- Prompt state does NOT persist across transition

REQUIRED CHANGE
1. Preserve PromptContext across transition into PreProjectChat

IMPLEMENTATION
- Create a shared PromptContextStore (React context or zustand):
  Fields:
    - textInput: string
    - attachments: PromptAttachment[]
    - origin: 'homepage'
- HomeHero writes to store instead of local state
- PreProjectChat reads initial state from store instead of props
- On cancel/reset, clear the store explicitly

DO NOT:
- Duplicate attachment state
- Reconstruct attachments in PreProjectChat

--------------------------------------------------

REQUIREMENTS

- Preview size: 200px height

   client/src/components/attachments/AttachmentPreview.tsx

SECTION 4 — CHAT ENTRY LOGIC (STRICT)
--------------------------------------------------

CURRENT LOGIC
- Attachments immediately open PreProjectChat
- classifyIntent() may bypass chat

NEW LOGIC
1. ALWAYS enter PreProjectChat if:
   - Attachments exist
   - Prompt confidence < execution-ready
   - Prompt is a question or ambiguous

2. ONLY skip chat if:
   - No attachments
   - classifyIntent() confidence >= execution-ready
   - Prompt is declarative and actionable

IMPLEMENTATION
- Update handleStartDesigning() logic:
  - Attachments => open chat (no exceptions)
  - classifyIntent() can suggest execution but not bypass confirmation UI
