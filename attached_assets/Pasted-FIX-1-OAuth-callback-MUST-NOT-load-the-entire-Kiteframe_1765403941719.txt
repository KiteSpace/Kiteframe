Instead, it must return a tiny HTML page that:

1. Calls window.opener.postMessage({ figmaAuth: "success" }, "<kiteframe origin>")
2. Closes the popup window

Implement callback response as:

res.send(`
  <html><body>
    <script>
      window.opener.postMessage({ figmaAuth: "success" }, window.location.origin);
      window.close();
    </script>
  </body></html>
`);

DO NOT redirect back to the app normally.

FIX #3 — In the main window, add a postMessage listener:

useEffect(() => {
  const handler = (event) => {
    if (event.data?.figmaAuth === "success") {
       queryFigmaStatus();  // calls /api/figma/status
       setShowPAT(false);
       setShowOAuth(false);
    }
  };
  window.addEventListener("message", handler);
  return () => window.removeEventListener("message", handler);
}, []);
