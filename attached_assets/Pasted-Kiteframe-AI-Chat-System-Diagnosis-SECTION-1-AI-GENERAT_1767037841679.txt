Kiteframe – AI + Chat System Diagnosis

SECTION 1 — AI GENERATION MECHANICS

Where is the authoritative “workflow generation” logic defined?

Is there a single function or prompt that both Home Prompt and KiteAI Chat call?

Or are there two independent generation pipelines?

At what point is the AI asked to generate nodes and edges?

First turn only?

After clarification?

After intent classification succeeds?

Is the AI instructed anywhere to include edge cases, failure paths, or conditions by default?

If yes, where?

If not, is there any post-processing step that attempts to add them?

Does the system have a notion of “minimum viable workflow complexity”?

e.g., minimum number of nodes

requirement for conditions/branches

or is any connected graph considered valid?

SECTION 2 — CONFIDENCE, CLARIFICATION, AND GATING

How is “confidence” computed?

What inputs affect it? (turn count, intent certainty, response length, schema coverage, etc.)

Is it deterministic or heuristic-based?

What does low confidence actually control today?

Asking follow-up questions?

Blocking generation?

Disabling UI actions (Apply / Create Workflow)?

Is there a hard confidence threshold that prevents generation?

If yes, why was this chosen instead of a soft degradation?

How does the system decide to enter “clarification mode”?

Is it automatic for certain intents?

Triggered by missing fields?

Or driven by model output?

Is there a maximum clarification turn limit?

If so, what happens when it’s reached?

Does it degrade gracefully or hard-stop?

SECTION 3 — HAPPY PATH BIAS & LINEAR OUTPUTS

Is there any explicit instruction or heuristic that discourages purely linear workflows?

Or is linear output currently considered acceptable?

Does the system ever penalize or flag “happy-path-only” workflows as incomplete?

If not, where would that logic best live?

Are there workflow-type–specific heuristics (onboarding, checkout, auth, etc.)?

Or is everything treated as a generic flow?

Is the AI optimized today for safety/minimality over completeness?

If so, what constraints were put in place to enforce that?

What are the concrete differences between Home Prompt and KiteAI Chat implementations?

Different prompts?

Different state machines?

Different UI affordances?

Why does KiteAI Chat generate immediately while Home Prompt often waits for clarification?

Is that intentional or accidental?

Are both paths using the same confidence model and thresholds?

If not, why were they split?

Which path is considered “canonical” internally?

If one had to win, which one should it be?

How are “quick actions” currently implemented in the chat UI (if at all)?

Derived from AI output?

SECTION 6 — APPLY / CREATE WORKFLOW ACTIONS

What conditions must be met for “Apply” / “Create Workflow” to be enabled?

Is it tied to confidence?

Tied to generation success?
