Single workflow on canvas
The simple case — no selection UI needed, the AI knows what to optimize.
	1.	User opens AI optimization with one workflow present — AI targets it automatically, no selection prompt shown
	2.	User accepts suggestion — optimized workflow appears offset from original (e.g. 200px down/right), original untouched
	3.	User dismisses/rejects — canvas unchanged
	4.	User runs optimization multiple times — each accepted result adds a new copy, none overwrite previous versions
	5.	User accepts, then undoes — undo removes the added workflow only, original remains
Multiple workflows on canvas
The selection UI path — this is your highest complexity surface.
	1.	User opens AI optimization with 2+ workflows — selection UI appears listing workflows by name/label
	2.	Workflows are unnamed — selection UI shows fallback labels (“Workflow 1”, “Workflow 2”) based on position or creation order
	3.	User selects a workflow, accepts result — only the selected workflow gets an optimized copy added; others untouched
	4.	User cancels at selection step — canvas unchanged, no AI call made (don’t burn credits on a cancelled selection)
	5.	User selects a workflow, then switches selection mid-conversation — AI context resets to newly selected workflow
The optimization conversation itself
	1.	User asks to simplify steps — AI suggests a version with fewer nodes, adds it on accept
	2.	User asks to add error handling — AI adds error/fallback paths to the optimized copy
	3.	User asks open-ended (“make this better”) — AI interprets and explains what it changed in the suggestion
	4.	User asks something unrelated to the workflow — AI redirects or clarifies scope
	5.	Multi-turn refinement — user accepts a suggestion, then asks to optimize that new workflow further (the accepted copy becomes the new target)
Edge cases and guardrails
	1.	Empty canvas — AI optimization is disabled or shows an empty state message
	2.	Workflow with no nodes — AI handles gracefully, doesn’t generate an empty duplicate
	3.	Very large workflow (50+ nodes) — AI still adds complete copy, doesn’t truncate
	4.	Canvas at max project limit — if adding a workflow would exceed some canvas object cap, surface a clear error before the AI call
	5.	Two users in same project (if multiplayer is ever a thing) — optimized workflow appears for both, attributed to the user who triggered it
Credit behavior
	1.	Credits deducted when AI generates the suggestion, not when user accepts — user shouldn’t lose credits for rejecting
	2.	Credits deducted once per optimization request, not per back-and-forth message in the refinement conversation
	3.	User runs out of credits mid-conversation — graceful block with upgrade prompt, partial conversation preserved
	4.	Selecting a workflow (step 9 cancel) costs zero credits
