3A.1 Data Extraction for Export
Task 3A.1.1: Implement an export aggregator that gathers:
  - project metadata (name/desc/categories)
  - selected workflows:
      - workflow name
      - workflow PRD sections
      - optional: a compact workflow summary generated from nodes/edges (no AI required)
  - linked references (sources list)
  - text↔node/edge link annotations (for formats that support it)
Acceptance:
  - A single function produces a canonical ExportPayload JSON.

Suggested new module:
  - client/src/lib/export/exportModel.ts
  - client/src/lib/export/buildExportPayload.ts

ExportPayload shape (recommended):
{
  project: { id, name, description?, categories?, createdAt?, updatedAt? },
  selection: { workflowIds: string[], includeProjectSummary: boolean, includeSources: boolean },
  workflows: Array<{
    workflowId: string,
    workflowName: string,
    prd: WorkflowPRD | null,
    semanticSummary?: {
      nodes: Array<{id,type,label?}>,
      edges: Array<{id,source,target,label?}>,
      decisionNodes?: string[]
    }
  }>,
  projectPRD?: ProjectPRD | null,
  sources?: Array<{ id, title, url, type, createdAt }>,
  links?: Array<TextBinding>,
  generatedAt: string
}

3B) TEXT ↔ NODE/EDGE LINKING SYSTEM (TRACEABILITY)
----------------------------------------

3B.0 Data Model
Task 3B.0.1: Define a stable TextBinding model (do NOT inject ids into markdown).
Recommended type:
type BindingTarget = 
  | { kind: 'node', nodeId: string }
  | { kind: 'edge', edgeId: string };

type TextBinding = {
  id: string;
  projectId: string;
  docType: 'workflow-prd' | 'project-prd' | 'notes';
  docId: string;
  sectionId?: string;
  startOffset: number;
  endOffset: number;
  exactText: string;
  target: BindingTarget;
  createdAt: string;
  updatedAt?: string;
  broken?: boolean;
  brokenReason?: 'TARGET_MISSING' | 'TEXT_CHANGED' | 'SECTION_MISSING';
}

Storage:
  - localStorage key: kiteframe-bindings-${projectId}

Acceptance:
  - CRUD operations exist and are unit tested.

Suggested files:
  - client/src/lib/linking/bindingsTypes.ts (new)
  - client/src/lib/linking/bindingsStorage.ts (new)

3B.1 Link Creation UX

UX requirements:

Acceptance:
