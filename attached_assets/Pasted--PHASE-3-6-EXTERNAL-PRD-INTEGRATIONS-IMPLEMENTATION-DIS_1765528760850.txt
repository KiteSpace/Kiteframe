PHASE 3.6 — EXTERNAL PRD INTEGRATIONS

SECTION A — CURRENT INTEGRATION INFRASTRUCTURE

1. Do we already have any integration framework or pattern in the codebase?
   - Examples:
     - integrations/ folder
     - OAuth helpers
     - service adapters
   If yes, list files and intended usage.

2. Is there an existing abstraction for:
   - Importing external text → internal models?
   - Exporting internal models → markdown / text?
   If yes, where is it implemented?

3. Are there any existing third-party API clients already in the repo (Jira, Google, Slack, etc.)?

SECTION B — AUTH & PERMISSIONS

4. Is OAuth infrastructure already present and reusable for:
   - Google APIs?
   - Jira APIs?
   Or would Phase 3.6 need to be **read-only, unauthenticated (manual paste / upload)** for MVP?

5. Are there any security or deployment constraints in Replit that affect:
   - OAuth redirect URLs
   - Storing access tokens
   - Server-side API calls?

6. For Phase 3.6 MVP, should integrations be:
   (a) Manual paste / upload only  
   (b) OAuth-based live fetch

   - Hybrid (JSON + markdown)?

9. For exports, which formats are acceptable?
