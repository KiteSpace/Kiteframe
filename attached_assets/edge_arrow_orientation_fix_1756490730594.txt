# Replit Fix Instructions: Edge Arrow Orientation

## Problem
Edge arrowheads are not displaying with proper orientation because the code is forcing a fixed rotation using `orient={arrowAngle}`. This ignores transforms (zoom, pan, scaling), so the arrow doesn’t follow the actual tangent of the path.

## Fix
Use SVG’s built-in auto-orientation instead of manual angles.

### Steps
1. Open the file where the edge markers are defined (likely `EdgeRenderer.tsx` or similar).
2. Find the `<marker>` definition inside your edge rendering code.
3. Replace the `orient={arrowAngle}` with `orient="auto"`.
4. Optionally adjust `refX` to `10` so the arrow tip aligns properly, and change `markerUnits` to `userSpaceOnUse` if you want arrowheads to stay the same size on zoom.

### Code Patch

```diff
- <marker 
-   id={markerId} 
-   viewBox="0 0 10 7" 
-   refX="9" 
-   refY="3.5" 
-   markerWidth="10" 
-   markerHeight="7" 
-   orient={arrowAngle}
-   markerUnits="strokeWidth"
- >
-   <polygon points="0 0, 10 3.5, 0 7" fill={stroke} />
- </marker>

+ <marker 
+   id={markerId} 
+   viewBox="0 0 10 7" 
+   refX="10" 
+   refY="3.5" 
+   markerWidth="10" 
+   markerHeight="7" 
+   orient="auto"
+   markerUnits="userSpaceOnUse"
+ >
+   <polygon points="0 0, 10 3.5, 0 7" fill={stroke} />
+ </marker>
```

### Notes
- `orient="auto"` automatically aligns the arrow with the path direction after all transforms.
- Use `orient="auto-start-reverse"` if you want arrows to flip correctly on reversed edges.
- If you prefer arrowheads to scale with line thickness, keep `markerUnits="strokeWidth"` instead of `userSpaceOnUse`.

## Result
After this change, arrowheads will always point correctly along the edge direction regardless of zoom/pan/transform.
