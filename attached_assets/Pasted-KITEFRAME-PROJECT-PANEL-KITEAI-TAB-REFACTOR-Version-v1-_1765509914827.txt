2.2. OPTIONAL (BUT RECOMMENDED): PROJECT-SCOPED CHAT PERSISTENCE

- Today, chat messages live only in React state and are lost on unmount.
- Since panel tabs may unmount/remount, we should persist per project.

Implementation pattern (inside ChatView):

- Use projectId prop in a useEffect/useState pair:

const STORAGE_KEY = `kiteframe-kiteai-chat-${projectId}`;

const [messages, setMessages] = useState<ChatMessage[]>(() => {
  if (typeof window === 'undefined') return defaultMessages;
  try {
    const raw = window.localStorage.getItem(STORAGE_KEY);
    return raw ? JSON.parse(raw) : defaultMessages;
  } catch {
    return defaultMessages;
  }
});

useEffect(() => {
  try {
    window.localStorage.setItem(STORAGE_KEY, JSON.stringify(messages));
  } catch {
    // fail silently
  }
}, [projectId, messages]);

- “defaultMessages” can be the current initial welcome message.

- DO NOT persist isDragging/isResizing/position/size in this refactor.

4.3. DEFAULT TAB LOGIC + PER-PROJECT PERSISTENCE

Goal:
- Initially, when a project is opened, KiteAI should be the default tab.
- If the user switches tabs, that choice should persist PER project.

Implementation:

a) Add a project-scoped storage key near top of ProjectPanel.tsx:

const PANEL_TAB_KEY_PREFIX = 'kiteframe-project-panel-tab-';

b) Derive an initialTab value using projectId:

const initialTab = React.useMemo(() => {
  if (typeof window === 'undefined' || !projectId) return 'kiteai';
  try {
    const saved = window.localStorage.getItem(
      `${PANEL_TAB_KEY_PREFIX}${projectId}`
    );
    return saved || 'kiteai';
  } catch {
    return 'kiteai';
  }
}, [projectId]);

c) Use a controlled Tabs component instead of fixed defaultValue if needed:

const [activeTab, setActiveTab] = React.useState(initialTab);

useEffect(() => {
  // If project changes, update activeTab from storage (or default to kiteai)
  if (!projectId) return;
  try {
    const saved = window.localStorage.getItem(
      `${PANEL_TAB_KEY_PREFIX}${projectId}`
    );
    setActiveTab(saved || 'kiteai');
  } catch {
    setActiveTab('kiteai');
  }
}, [projectId]);

// Persist on change
useEffect(() => {
  if (!projectId || !activeTab) return;
  try {
    window.localStorage.setItem(
      `${PANEL_TAB_KEY_PREFIX}${projectId}`,
      activeTab
    );
  } catch {
    // ignore
  }
}, [projectId, activeTab]);

d) Wire Tabs to activeTab:

<Tabs
  value={activeTab}
  onValueChange={setActiveTab}
  className="flex h-full flex-col"
>

- Remove any existing defaultValue="layers" or similar.
- If Tabs is already controlled, merge with the existing logic rather than overwrite.
