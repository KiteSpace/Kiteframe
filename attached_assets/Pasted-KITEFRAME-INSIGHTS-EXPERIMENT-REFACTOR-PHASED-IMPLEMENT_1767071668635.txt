KITEFRAME — INSIGHTS / EXPERIMENT REFACTOR
PHASED IMPLEMENTATION INSTRUCTIONS (NON-NEGOTIABLE)

PURPOSE
Refactor diagnostics, experiments, and insights so that:
- The canvas is judgment-free
- Analysis is opt-in
- Experiments are explicit, user-initiated exploration tools
- “Explore Solution” is eliminated as a separate concept
- PRD generation remains non-actionable and clean

DO NOT introduce new auto-analysis, badges, or system-created experiments.

=====================================================================
GLOBAL INVARIANTS (MUST HOLD AT ALL TIMES)
=====================================================================

1. Diagnostics NEVER auto-run.
2. The canvas NEVER shows judgmental indicators (badges, warnings, risk icons).
3. Experiments are ALWAYS explicitly created by user intent.
4. Insights may suggest exploration but NEVER mutate the workflow.
5. PRDs NEVER auto-include risks or diagnostics.
6. Deletions come before additions.
