========================================
KITEFRAME FEATURE EXPORT - CONTENTS LIST
========================================

This export contains the core advanced features from the KiteFrame library v1.0.0:
- Collaboration Features (Real-time multi-user)
- Version Control (History & Undo/Redo)
- Export Capabilities (Utilities & Components)
- Advanced Interactions (Edge Reconnection, Multi-select, etc.)

========================================
COLLABORATION FEATURES (Real-time Multi-user)
========================================

📁 components/collaboration/
├── YjsProvider.tsx
│   Purpose: Real-time state synchronization provider
│   Features: WebSocket management, Yjs integration, room isolation
│   Dependencies: yjs, y-websocket
│
├── YjsLiveCursor.tsx
│   Purpose: Live cursor tracking for collaborators
│   Features: Real-time cursor positions, user colors, smooth movement
│   Dependencies: YjsProvider
│
├── CollaborationUI.tsx
│   Purpose: User presence and avatar display
│   Features: Active users, online status, emoji avatars
│   Dependencies: YjsProvider
│
├── CommentSystem.tsx
│   Purpose: Node-attached commenting system
│   Features: Comment threads, replies, timestamps, user attribution
│   Dependencies: YjsProvider, user identity
│
├── CanvasCommentSystem.tsx
│   Purpose: Canvas-positioned comments
│   Features: Click-to-place, draggable markers, visual connectors
│   Dependencies: YjsProvider, canvas coordinates
│
└── ChatSystem.tsx
    Purpose: Real-time chat interface
    Features: Message history, typing indicators, emoji support
    Dependencies: YjsProvider, user identity

========================================
USAGE EXAMPLES
========================================

1. COLLABORATION SETUP:
```tsx
import { YjsProvider } from './collaboration/YjsProvider';
import { LiveCursors } from './collaboration/YjsLiveCursor';

<YjsProvider roomId="workflow-123">
  <KiteFrameCanvas />
  <LiveCursors />
</YjsProvider>
```

2. VERSION CONTROL:
```tsx
import { HistoryProvider } from './providers/HistoryProvider';

<HistoryProvider>
  <YourWorkflowApp />
</HistoryProvider>
```

3. ADVANCED INTERACTIONS:
```tsx
import { EdgeHandles } from './advanced/EdgeHandles';
import { NodeHandles } from './NodeHandles';

// Edge reconnection
<EdgeHandles 
  edge={selectedEdge}
  onEdgeReconnect={handleReconnect}
/>

// Node quick-add handles
<NodeHandles 
  node={node}
  onQuickAddNode={handleQuickAdd}
/>
```

4. MULTI-SELECTION:
```tsx
import { useMultiSelect } from './hooks/useMultiSelect';

const { selectedNodes, selectNode, clearSelection } = useMultiSelect();
```

========================================
INTEGRATION NOTES
========================================

1. **Collaboration Features**: Require WebSocket server for real-time sync
2. **Version Control**: Works independently, stores history in memory/localStorage
3. **Advanced Interactions**: Require canvas coordinate system and viewport management
4. **Export Utilities**: Can be used standalone or integrated with parent application

📦 State Management Layer

📦 Utility Layer
