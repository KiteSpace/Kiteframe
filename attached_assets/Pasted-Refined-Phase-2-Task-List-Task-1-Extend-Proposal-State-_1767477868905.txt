3. Two Subtle Pitfalls to Watch For (Important)
Pitfall 1: Variant Drift on Accept

Make sure Accept always commits the currently active variant, not:

The default

The last-generated

The first-generated

This sounds obvious, but it is the most common Phase 2 bug.

Guardrail: Accept handler should read proposal.activeVariant at click time.

Pitfall 2: Implicit “Winner” Bias

Do not:

Visually emphasize Proposed more than Alternative

Auto-switch back to Proposed after preview

Add language implying correctness

Comparison must feel neutral, even if one is recommended.

You can bias later. Not now.
