STEP 5 — BADGE → EXPLORE SOLUTION TRIGGER LOGIC
5.1 Badge metadata

Ensure badges include:

type Badge = {
  id: string
  type: 'risk' | 'inconsistency' | 'missing_dependency' | 'ambiguity' | ...
  severity: 'low' | 'medium' | 'high'
  systemGenerated: boolean
  actionable: boolean
}

5.2 Trigger conditions (ALL required)
function shouldTriggerExploreSolution(badge: Badge): boolean {
  return (
    badge.systemGenerated === true &&
    badge.actionable === true &&
    badge.severity !== 'low'
  )
}

5.3 UI behavior

If shouldTriggerExploreSolution === true:

Show CTA: Explore solution

On click:

Create Explore Solution node

Anchor it to the originating workflow node

Pass badge context (NOT conclusions)

5.4 Non-triggers

Do NOT trigger Explore Solution for:

Informational badges

User-created annotations

Cosmetic warnings

Low-confidence heuristics
