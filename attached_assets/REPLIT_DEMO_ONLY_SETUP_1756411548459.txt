KITEFRAME UI — REPLIT FIX (DEMO-ONLY UPLOAD)
===========================================

Problem Summary
---------------
You uploaded ONLY the demo files. The demo imports `@lib/*` (the KiteFrame library) and `@ai/*` (AI layer). Without the library source (or aliases to local files), Vite can’t resolve imports and the canvas won’t behave (CSS missing = broken drag/connect).

This guide makes the demo self‑contained by adding **local stubs** for `@lib` and `@ai`, aliases in Vite, and Replit configs so it always runs the demo.

Files you will add from this bundle
-----------------------------------
• .replit                    → forces Replit to run the demo dev server
• replit.nix                 → Node 20 on Replit
• vite.config.ts             → alias @lib → src/lib/kiteframe, @ai → src/ai
• src/lib/kiteframe/...      → minimal library stubs (canvas, edges, handles, utils, CSS)
• src/ai/...                 → minimal AI client/provider stubs

Your existing demo files stay the same (index.html, package.json, tsconfig.json, src/App.tsx, src/main.tsx, src/components/*).

Step 0 — Use Node 20 on Replit
------------------------------
Create `replit.nix` at project root (or use the one in this zip):

{ pkgs }: {
  deps = [
    pkgs.nodejs_20
    pkgs.nodePackages.typescript
  ];
}

When prompted, click **Rebuild**.

Step 1 — Force Replit to run Vite in this folder
------------------------------------------------
Create `.replit` at project root (or use the one in this zip):

run = "npm install --no-fund --no-audit && npm run dev -- --host 0.0.0.0 --port 5173"

(If port 5173 conflicts in your repl, change to 3000.)

Step 2 — Vite aliases so demo can resolve @lib and @ai
------------------------------------------------------
Create `vite.config.ts` at the project root (overwrite if Replit created one):

import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import { resolve } from 'path'

export default defineConfig({
  plugins: [react()],
  resolve: {
    alias: {
      '@lib': resolve(__dirname, 'src/lib/kiteframe'),
      '@ai': resolve(__dirname, 'src/ai')
    }
  }
})

Step 3 — Add minimal local library + AI stubs
---------------------------------------------
Copy the folders from this zip:
  src/lib/kiteframe/{components,styles,utils,types.ts}
  src/ai/{types.ts, AiProvider.tsx, OpenAICompatClient.ts}

Make sure your `src/App.tsx` includes:
  import '@lib/styles/kiteframe.css';

Step 4 — First run
------------------
1) Open Replit shell (from project root):
   npm install --no-fund --no-audit
2) Click **Run** (or let `.replit` do it)
3) Open the web preview → Vite dev server should show the demo

Expected behavior
-----------------
• Background drag pans the canvas
• Wheel/pinch zoom (cursor-anchored)
• Nodes follow cursor on drag
• Handle-to-handle connections
• Shift+drag multi-select
• AI Settings modal “Quick Test” works (if you enter a temp API key)

If the preview doesn’t load:
----------------------------
• Check console for alias errors → verify `vite.config.ts` was added at project root.
• If Replit boots a different app, confirm `.replit` exists at project root.
• If pointer events look broken, ensure `import '@lib/styles/kiteframe.css'` is present in `src/App.tsx`.
• If Replit requires another port, change the port in `.replit` to 3000.

Security note
-------------
The demo can store a **temporary** key in localStorage if you opt in (for quick tests). Do **not** ship real keys to browsers in production—use a secure proxy or your backend to attach auth and rate limits.
