2) SPACEPROBE: SMART LAYOUT THAT AVOIDS OVERLAP
Problem:
parseGeneratedBranch() lays out right-to-left with constant spacing and can overlap existing nodes.

Deliverable:
A new lightweight utility that chooses direction (horizontal/vertical) and offsets to avoid collisions.

2.1 Create SpaceProbe utility
New file:
- client/src/lib/kiteframe/utils/SpaceProbe.ts

Functions:
A) getNodeRect(node): returns a bounding rect in world coords
- Use node.position.x/y and node dimensions.
- If width/height are stored in node.style or node.data.style, normalize in one place.
- Assume defaults if missing: width=200 height=120 (or whatever your real node default is)

B) rectsOverlap(a, b): boolean
C) scorePlacement(candidateRects, existingRects): number
- score = total overlap count (primary)
- tie-breaker = total overlap area (optional)
- tie-breaker = distance from origin (optional)

D) probeAvailableSpace(origin, existingNodes, nodeCount, axisPreference?): returns:
{
  direction: 'right'|'left'|'down'|'up',
  startOffset: {x,y},
  spacing: {x,y},        // vector spacing
  laneOffset: {x,y}      // secondary offset when collision persists
}

2.2 Implement direction sampling
Within probeAvailableSpace:
- Candidate directions: right, left, down, up
- For each direction:
  - generate candidate rects for N nodes using baseline spacing:
    - horizontal: dx=280 dy=0
    - vertical: dx=0 dy=200–260 (pick sane default)
  - compute score vs existingRects
- Choose lowest score direction.

2.3 Collision fallback strategy (required)
If best candidate still overlaps:
1) Increase spacing (1.5x)
2) Try switching axis
3) Apply laneOffset diagonal (e.g., +120,+120) and rescore

2.4 Integrate SpaceProbe into branch generation layout
Files:
- client/src/ai/workflow/generateWildCardBranch.ts (parseGeneratedBranch)
- OR the workflow-editor.tsx positioning layer if parseGeneratedBranch only parses AI JSON

Change:
- Stop hardcoding right-to-left positions.
- Use SpaceProbe result to compute node positions before setNodes().

Acceptance:
- Generating branches near dense areas does not overlay existing nodes in typical cases.
- At minimum, collision rate is dramatically reduced and visibly better than today.
- Direction is chosen sensibly:
  - If right side is crowded, it flips to vertical or left.

Instrumentation (required):
Add a console log (guarded by dev flag) on generate:
[ExperimentLayout] experimentId=... direction=... score=... fallbackUsed=...

4.2 Batched accept
When Accept happens:
- Ensure:
  - meta.speculative removed from all generated nodes
  - origin node converts to process (if not already)
  - origin node.meta.experiment persists
  - Any “preview ui” flags removed (data.ui.preview)
- Wrap all mutations in a single batch so it becomes ONE undo step:
"Accept experiment branch"

Acceptance:
- Reject does not change historyIndex/historyLength.
- Accept creates exactly one history entry.
- Undo after accept reverts the accept state (restores speculative or removes accepted nodes depending on your intended undo semantics; pick one and be consistent).
